平台差异
  1. W
    Web 浏览器：「开始使用」先进 S2 自动连本机 daemon（经 ws 探本机，不显端口，过场主文案「正在连接本机 daemon…」）→ 连上落主页；连不上才落选择器（兜底 · 无扫码 · 带「重试本地」· 副标题转「没检测到本地 daemon」）。一次性品牌欢迎仍保留（首次访问）。
  2. M
    手机 native：本机无 daemon、自动连探不到 → 兜底到选择器（纯远程），扫码连电脑主机为主 CTA；粘链/直连为次。连上后即远程遥控本机代理（relay E2E）。
  3. D
    桌面 Electron：directPipe 自动连本机 → 走 S1→S2 主路径（与浏览器同路径，仅 transport 不同），连不上落 S4 错误态。
  4. R
    重开自愈（全平台）：已看过欢迎/老用户后续启动不显欢迎→静默重试本机一次→连上进主页，否则落 picker（桌面落 S4）；「连接远程」是会话级意图、不跨重启，重开仍先重试本机。
主页 · 左侧对话树

项目 → 根对话 → subagent

完整视觉与全状态以嵌入的需求设计稿为准。项目、根对话、subagent、分组标题与空提示均为 36px 单行；项目显示文件夹图标 + 标题，根对话和 subagent 都只显示标题，不显示状态点、图标、数量或行尾操作。三类节点的补充信息都由右侧 hover 卡片承载；subagent 卡片显示它自己的名称、最后一次使用时间与提供方，操作目录在没有独立工作区时仅为展示而继承父级目录上下文。管理操作统一进入右键菜单。

交互注解
  1. L
    布局：桌面左栏常驻；移动/紧凑态延后。项目、根对话、subagent、分组标题和空提示统一 36px 单行。
  2. S
    状态：项目、根对话与 subagent 均有清晰 hover 背景；点击根对话或 subagent 后显示持续选中背景。项目显示目录信息卡，根对话与 subagent 显示各自的对话信息卡； 审核中、报错、进行中等状态判断与视觉后续单独确认。
  3. R
    右键菜单：行尾无三点、快捷新建或其它动作按钮。项目菜单新增“新对话”，并保留置顶、 Finder、工作树、重命名、归档与移除；根对话和 subagent 共用原对话菜单。
  4. C
    点击效果：项目切换展开；根对话进入中区；subagent 打开或聚焦右栏对话；chevron 只控制子级展开。
主页 · 中区真实对话

根对话消息流、内嵌草稿与固定 Composer

左侧点击根对话后，中区复用既有真实对话面板，展示 daemon timeline、工具调用、附件、 subagent 轨道与 Composer；点击“新对话”时保持主页 URL 与三栏布局，在中区原位显示底部 Composer，发送后内容从其上方出现。首次进入即默认显示未绑定项目的新对话草稿，不经过“选择一个对话”空态；选择真实工作目录后才绑定项目。完整画面与状态见本需求设计稿。

交互注解

    布局：桌面自适应填满左栏与右侧工具之间的剩余宽度；工作目录固定在 Composer 顶部上下文条；新对话首帧、乐观发送和真实 agent 接管共用同一个底部 Composer 锚点；右栏最大化时按壳规则隐藏。
  2. S
    状态：首次加载、未绑定草稿、目录选择中、目录选择失败、已绑定、新建中、新建失败、 正常、运行、错误、离线与归档均有出口；首次加载成功后直接进入未绑定草稿，切换 agent 不残留上一条消息，取消、选择失败与创建失败均保留草稿。
  3. R
    右键菜单：中区不新增右键菜单；左树管理菜单保持原定义。
  4. C
    点击效果：顶部“新对话”创建未绑定草稿，项目菜单入口预选该项目；点击目录栏选择 host 真实目录，未选目录发送时提示先选择；首次发送后消息从 Composer 上方出现并原位接管真实 agent；根对话切换中区；subagent 保持中区并打开右栏；消息文件链接在当前 workspace 的右侧文件面板打开。

主页 · Composer · 已实现，待 Gate 3 验收

新对话、进行中对话与运行配置

Composer 改为单一连续输入表面：顶部工作目录上下文条、正文输入区、底部工具与运行配置。 底栏左侧只保留统一“+”，右侧以三个同规格且间隔 6px 的文字标签承载模型、英文推理强度和 provider 真实运行模式，再放上下文与发送；所有点击槽位统一高度、圆角和图标尺寸。模型选择使用贴着触发器的单列锚定下拉，顶部承载提供方与中转站。新对话与进行中对话、队列操作、模型下拉、强度/模式菜单、上下文/额度、紧凑态和关键异常状态见完整设计稿。

交互注解
  1. L
    布局：目录、输入和底栏合为一个 Composer；宽度和底部锚点在新对话、运行、队列与 错误状态下保持稳定。底栏只有统一“+”、模型/强度/模式三个文字标签、上下文和发送；三个 标签之间固定留 6px，所有槽位统一 32px 高、6px 圆角和 16px 图标，只有发送/停止使用实色。桌面模型选择是最多 430px 且列表内部滚动的锚定下拉，紧凑态使用底部 sheet；780px 桌面与 320px 紧凑宽度均不换行、不裁切、不横向滚动。
  2. S
    状态：工作目录、提供方、中转站、模型、推理强度、运行模式、上下文和账号额度均有默认、 加载、空、错误与离线状态；能力不支持的控件不渲染灰色占位。紧凑态把附件、`@`、语音、 强度、模式与 provider feature 收进“+”，入口移动但功能不丢失。
  3. C
    点击效果：新对话中目录、提供方、中转站、模型、强度和模式均可调整；创建后目录和 提供方锁定，其余运行配置按下一条消息生效；每条待发消息右侧可删除或强制发送；上下文入口 展开对话 token 占用与当前官方/中转站运行路由返回的 windows、balances 和 details；5h、7 天只是可能返回的窗口示例。
  4. B
    边界：中转站是 API 供应商，不是 host Relay；Plan / Build 等是运行模式而非模型， 推理档位保留英文，额度窗口不硬编码。深度配置仍进入设置；本需求不修改协议。

首次两侧收起，返回恢复工作现场

每条中区根对话和每个新对话草稿独立记忆文件目录树、右侧工作区与 Workbench 页签。首次进入不继承上一条对话的工具状态；返回旧对话时恢复离开前现场。

交互注解
  1. L
    布局：中区与左侧全局对话树保持；文件目录树和右侧工作区按当前中区对话独立显示。
  2. S
    状态：首次目标两侧关闭、Workbench 为空；已访问目标恢复开关、最大化、页签集合、顺序和焦点；draft 接管成 agent 时保持。
  3. R
    右键菜单：不新增；右侧页签仍为关闭、关闭其它和关闭全部。
  4. C
    点击效果：点击根对话或新对话先保存当前现场再恢复目标；subagent 只加入当前右侧工作区，不建立新的中区视图周期。
