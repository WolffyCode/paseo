# 需求 · 对话视图状态记忆

> 日期：2026-07-28 · 状态：开发中 · 配套 UI：[ui.html](./ui.html)

## 1. 目标

把主页中区的每条根对话或新对话草稿视为独立的工作视图。用户首次进入一个视图时从干净画布开始，返回访问过的视图时恢复离开前的右侧工具布局和页签现场。

## 2. 入口与流程

1. 首次打开主页的默认新对话、点击左栏“新对话”、项目菜单“新对话”，以及首次点击一条尚未访问的根对话时，文件目录树与右侧工作区均默认收起。
2. 用户可在当前对话内独立展开或收起文件目录树、右侧工作区，并在右侧工作区打开、关闭、聚焦或排序页签。
3. 切换到另一条根对话或新对话时，系统保存当前对话的两侧展示状态、右侧最大化状态和右侧工作区页签现场，再进入目标视图。
4. 目标视图第一次进入时使用默认收起状态和空 Workbench；目标视图此前访问过时恢复它离开前的状态。
5. 新对话草稿创建成真实根对话时沿用原草稿的视图状态和右侧页签，不把成功创建误判为一次新的首次进入。

## 3. 状态

- 首次访问：文件目录树关闭、右侧工作区关闭、右侧非最大化，Workbench 为空。
- 已访问：恢复该对话最后一次离开时的两个开关、最大化状态、页签集合、页签顺序和当前页签。
- 当前视图：开关与页签操作只改变当前对话，不影响其它对话。
- 草稿接管：draft 变为真实 agent 时状态无闪烁、无清空。
- 收起：收起右侧工作区只隐藏表面，不销毁页签；再次展开仍是原现场。
- host 切换：不同 host 的视图状态互不复用；新 host 的视图按首次访问处理。
- 重载：本需求保证当前客户端会话内的切换记忆；页面重载后的恢复不在本轮范围。

## 4. 边界

- 左侧全局对话树的显隐和宽度不按对话记忆。
- 文件目录树与右侧工作区的宽度继续沿用现有 workspace 级规则，本需求只改变展示/收起、最大化和 Workbench 页签生命周期。
- 不复制消息、文件内容、Composer、timeline 或 daemon 数据。
- 不新增协议、RPC、provider 或模型机制。
- subagent 仍在当前中区对话所属的右侧工作区打开，不创建新的中区视图周期。

## 5. 验收

1. 在对话 A 展开文件目录树和右侧工作区并打开多个页签，切到首次访问的对话 B 后两侧均关闭。
2. 在 B 打开不同页签后切回 A，A 的两侧状态、页签顺序和焦点原样恢复。
3. 再切回 B，B 的现场独立恢复，A 与 B 不串状态。
4. 点击“新对话”得到新的默认关闭视图；多个新草稿彼此独立。
5. 草稿首次发送并接管成真实 agent 后，右侧工作区状态与页签不丢失。
6. 仅收起再展开右侧工作区不丢页签。
7. 同一 workspace 下的两条根对话仍各自拥有独立的视图状态。
