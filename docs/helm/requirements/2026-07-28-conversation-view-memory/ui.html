交互注解

布局
桌面三栏壳不变；文件目录树和右侧工作区按当前中区对话独立显示。紧凑/手机沿用现有单面板导航，本轮不新增并排布局。
状态
默认：首次视图两侧关闭。active：已访问视图恢复离开前的开关、最大化、页签、顺序与焦点。加载、错误、离线沿用各内容表面现有状态。
hover
无新增 hover；顶部区域开关和页签沿用现有反馈。
右键菜单
不新增菜单；右侧页签继续提供关闭、关闭其它和关闭全部。
点击效果
点击根对话或新对话先保存当前现场，再恢复目标现场；首次目标使用关闭/空默认态；返回旧目标恢复；subagent 只打开当前目标的右侧页签，不切换中区视图。
禁用/空/运行
无 workspace 时两侧工具保持不可用；空 Workbench 沿用 launcher；运行中的对话切换不销毁后台 agent 状态。
