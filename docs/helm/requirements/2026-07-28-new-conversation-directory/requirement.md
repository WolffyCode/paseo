# 需求 · 新对话工作目录

> 日期：2026-07-28 · 状态：开发中 · 配套 UI：[ui.html](./ui.html)

## 1. 目标

让主页新对话像 Codex 一样先作为独立草稿出现，并在 Composer 上方明确选择工作目录。只有选中工作目录后，草稿才绑定到该目录对应的真实项目。

## 2. 入口与流程

1. 首次进入主页或点击左栏顶部“新对话”时，中区创建一个未绑定项目的新草稿，不沿用上一条对话或任意默认项目。
2. 项目右键菜单“新对话”仍创建预选该项目工作目录的草稿。
3. 新草稿的 Composer 顶部上下文条固定显示工作目录；未选择时显示“选择工作目录”，已选择时显示目录名称与可辨认路径。
4. 点击工作目录栏：本机桌面使用系统目录选择器；浏览器、移动端和远程 host 使用 host 目录选择面板。
5. 选择目录成功后，草稿绑定 host 返回的真实 workspace；该目录成为项目，首次发送创建的根对话归入该项目。
6. 取消选择时保留未绑定草稿和已输入内容，不创建项目；用户可继续编辑、重新选择目录或切换其它对话。
7. 未选择工作目录时发送不启动 agent，并在 Composer 附近提示先选择工作目录。

## 3. 状态

- 未选择：独立草稿、目录入口可用、输入内容可编辑、发送受阻并有明确提示。
- 选择中：目录入口显示处理中，避免重复提交；Composer 和草稿内容保持。
- 已选择：显示真实目录，允许首次发送；发送期间目录锁定。
- 选择失败：保留草稿与输入，显示 host 返回的错误，可重试。
- 离线：保留草稿与输入，目录选择和发送禁用，等待重连。
- 项目预选：从项目菜单进入时直接显示该项目目录，仍可在首次发送前改选。

## 4. 视觉与交互

- 左侧根对话的持续选中背景必须明显深于 hover 背景；hover 与选中不能只靠同一颜色表达。
- 工作目录上下文条属于 Composer 的连续输入表面，不因目录状态、错误或首次发送产生位置跳动。
- 目录栏使用文件夹图标；未选文案是命令，已选文案优先显示目录名，完整路径作为次要信息。
- 本需求不新增行尾操作按钮或新的右键菜单。

## 5. 边界

- 不创建伪 workspace，不猜测工作目录，不回退到旧 `/new` 路由。
- agent provider 仍要求真实 `cwd`；“未选目录的对话”仅指尚未启动 agent 的客户端草稿。
- 不新增 provider、模型或 agent 创建协议。
- 右侧并行对话页签的目录改选延后；本轮只改变主页中区的新对话入口。

## 6. 验收

1. 首次进入主页显示未绑定项目的新草稿，左树没有根对话被选中。
2. 从任意旧对话点全局“新对话”后，不继承旧对话目录；输入内容在取消目录选择后仍保留。
3. 未选目录发送不会创建 agent，并出现明确提示。
4. 选择一个真实目录后目录栏更新；首次发送成功后新根对话归入该目录对应项目。
5. 从项目右键进入时预选该项目目录，首次发送前可改选。
6. 目录选择失败、取消与离线均不清空草稿。
7. 左树选中背景在浅色和深色主题中均明显区别于 hover。
