08 · 关键状态

异常不改变 Composer 骨架

状态反馈进入原控件或 Composer 上沿；不新增一排图标，不让加载、错误或离线把底栏顶高。

入口明确 · 失败可恢复
状态矩阵
配置加载
运行配置条显示单行骨架；输入保留，发送暂不可用。
模型为空
模型段显示“无可用模型”；下拉提供切换中转站和管理配置出口。
中转站错误
保留上一组有效配置；下拉显示原因、重试和管理中转站。
Host 离线
保留输入与待发队列；配置和发送禁用，Composer 上沿显示等待重连。
强制发送失败
动作原位恢复为“重试强制发送”；删除仍可用，不影响其它待发项。
额度部分缺失
只展示真实返回的 windows、balances 或 details；错误留在信息框内重试。
加载 / 空控件占位不改变高度；模型为空必须保留切换中转站的出口。
错误 / 离线输入和队列永不丢；恢复后沿用最后有效配置继续。
额度对话上下文与账号额度独立失败；其中一组不可用不隐藏另一组。
右键与点击Composer 不新增自定义右键菜单；输入区保留平台文本菜单。所有配置从对应段或“+”点击进入，键盘 focus 使用同一 32px 槽位边界。
