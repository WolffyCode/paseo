  8. 8
    状态点 / 角标：纯指示，无点击动作（角标 = subagent 总后代数，非仅直接子数）。

    设置入口（左栏最下方）：壳级按钮，点击进入设置页模式（见 shell §6.B.13）；本稿只画其在左栏的上下文落位，交互归壳。

布局 + 状态
布局
桌面 only；hover 卡片 / hover 尾部动作仅 web 桌面（原生触屏用「常显」替代 hover，同 docs/hover.md 约定）。
hover
行底色 --accent；尾部动作淡入、角标淡出（同一槽位互斥，不挤占宽度）。
选中
--secondary（见头部 note 的「与现有实现差异」披露）；右键该行时同时进入选中态。
重命名
行变输入框 + 蓝聚焦环；此态下该行不可 hover/选中切换，其余行操作照常。
拖拽
被拖行半透明 + 抓手；目标位置显 2px 蓝色放置线；其余行不变淡（仅被拖行变淡，与右侧栏 tab 拖拽的「其余变淡」不同——树行更密集，全变淡会影响可读性，故只淡化被拖行本身）。
禁用（菜单项）
不透明度 0.48、cursor:not-allowed，不响应 hover。
pending（移除中）
菜单项显 spinner + 文案变化，菜单不自动关闭，允许用户继续查看/操作其它项。
