交互注解

布局
右栏沿用页签栏；对话内容填满页签下方，每个页签自带 workspace。
点击
subagent 打开只读页签；页签聚焦；× 关闭；“+”→“对话”直接打开右侧草稿。
拖拽
仅根对话可拖；有效悬停高亮中区；释放后右栏打开且中区不变；取消无副作用。
新建
沿用当前中区的真实 workspace；不显示目录选择；中区未选目录时禁用。
只读
subagent 无 Composer、不可文件拖入；历史、运行输出和文件链接仍可用。
运行
可编辑根对话与 draft 沿用 Composer、流式输出、创建中和失败重试。
离线
新建与发送禁用，已加载内容保留并显示重连反馈。
右键
页签菜单：关闭、关闭其它、关闭全部；无其它新增右键菜单。
