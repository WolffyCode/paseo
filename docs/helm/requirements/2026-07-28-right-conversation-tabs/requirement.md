# 需求 · 右侧对话页签

> 日期：2026-07-28 · 状态：开发验证中 · 配套 UI：[ui.html](./ui.html) · canonical：`docs/helm/product.md`

## 1. 目标 & 用户价值

让用户在中区主对话保持不变时，于右侧工作区并行查看 subagent、继续其它根对话并直接开始新对话。

## 2. 范围

- **做**：subagent 点击打开只读对话页签；根对话拖入中区打开可编辑页签；右栏沿用当前中区真实 workspace 直接新建对话；agent 去重、draft 独立、创建后原位接管；页签聚焦、关闭与排序。
- **不做**：不新增 provider、模型选择机制、协议或 RPC；不改变中区主对话选择；不设计审核中/报错/进行中的左树行内视觉。

## 3. 流程

1. 点击左树 subagent，右栏自动展开并打开对应只读页签；再次点击聚焦已有页签。
2. 桌面把有工作目录的根对话拖到中区；有效悬停显示 drop 高亮，释放后右栏展开并打开可编辑页签，中区内容不变；取消拖动不产生页签。
3. 在当前中区已有真实 workspace 时，从右栏空态点击“对话”，或在页签栏点击“+”再选“对话”，沿用当前 workspace 直接创建右侧 draft，不显示目录选择；中区未选目录时入口禁用。
4. 左栏新建与右栏新建只改变草稿挂载位置：前者进入中区，后者进入右侧 Workbench；Composer 与首次发送逻辑一致。
5. 首次发送成功后，draft 原位接管真实 agent；daemon 更新把它加入左树当前 workspace 对应项目。失败时保留 draft、输入和重试入口。
6. 关闭页签后聚焦相邻页签；关闭全部后回到空态。离线时新建入口禁用，已加载只读内容保留。

## 4. 屏与全状态

- `ui.html#sRT1`：右栏对话页签。默认显示消息流；subagent 显示只读提示而无 Composer；根对话显示 Composer。
- `ui.html#sRT2`：当前目录新建规则。右栏不显示第二套目录选择；中区没有真实 workspace 时入口禁用。
- hover：页签、关闭按钮、新建入口和 drop 区有明确反馈。
- active：当前页签使用选中背景；有效 drop 使用边框和浅色背景。
- 运行/加载/错误：复用真实对话与 draft 的既有状态。
- 离线：禁止新建和发送，保留已加载内容与重连反馈。
- 右键菜单：页签三个命令为“关闭”“关闭其它”“关闭全部”；其它区域无新增右键菜单。

## 5. 边界与依赖

- 依赖现有 Workbench、真实 AgentConversationPanel、WorkspaceDraftAgentTab、session/daemon 更新和 workspace 目录数据。
- Web/Electron 支持 HTML5 拖拽；原生端不显示拖拽反馈，仍可通过 subagent 点击和右栏新建完成任务。
- subagent 的只读约束由入口语义强制，不依赖 provider 是否写入 observed 标记。
- 工作目录必须来自 host 的真实 workspace；不得猜测路径或创建伪 workspace。

## 6. 验收标准

1. 点击 subagent 能在右栏显示自己的真实历史，且没有可输入 Composer。
2. 根对话拖入中区后，中区选择不变，右栏新增可编辑对话页签。
3. 重复打开同一 agent 只聚焦，不产生重复页签；两个 draft 可并列。
4. 当前中区已有真实 workspace 时，右栏空态和“+”均能沿用当前 workspace 直接创建 draft；中区未选目录时入口禁用。
5. 新建成功后页签原位接管，左树最终在当前 workspace 对应项目显示该对话；失败可原位重试。
6. 同一目录已有根对话的标题不因新对话创建而改变。
7. 文件链接、页签关闭、关闭其它、关闭全部和拖动排序继续工作。
8. 离线、中区无真实 workspace、加载和错误均有明确出口，无死路。
