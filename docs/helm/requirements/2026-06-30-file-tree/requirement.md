# 需求 · 右侧目录树（文件树）· 内容兑现

> 日期：2026-06-30 · 状态：草拟 · 配套 UI：[ui.html](./ui.html) · canonical：docs/helm/product.md
> **只写 WHAT**（见 [standards.md](../../standards.md) §7）—— 全文不含组件名 / 函数名 / 接口名 / 文件名 / 协议名 / RPC 名 / 状态容器名 / 代码片段 / 实现路子。怎么实现是架构师与开发者的事。
> **定位**：本需求只填**已存在的目录树空容器**的内容（壳子 §7.e.26「文件树展开 / 选中 / 预览」的兑现 + 董事长新增硬性需求）。**不重定义**壳布局 / 目录树 toggle / 宽度记忆 / 拖拽——那些已是壳行为（见 `2026-06-28-shell`），本需求只关心「这个空容器里装什么、怎么用」。

## 1. 目标 & 用户价值

**一句话目标**：把对话页右侧的目录树空容器填成一棵**可用的文件树**——展开时自动落在「当前对话的工作目录」或「桌面」为树根，逐层展开 / 收起、选中文件、**按文件名或文件内容搜索**、**经系统文件选择器切换树根目录**，每种文件类型都有**清晰可区分的专属图标（不同字形 / 配色，足够醒目，一眼能分辨代码 / 图片 / 配置 / 文档 / 锁文件等）**；目录树还**支持右键上下文菜单**（含新建 / 重命名 / 剪切复制粘贴 / 在 Finder 中显示 / 在文件中查找 / 复制路径 / 将文件添加到聊天等文件写与联动操作）；并把这套「目录树能力」**对外开放为公共能力**，供后续「对话选目录」「点对话联动展示该对话目录」复用。

**用户为什么需要它**：

- **为什么要文件树？** 用户在对话里让 agent 改代码 / 看文件时，需要一眼看清工作目录的结构、定位到某个文件——空容器没有任何用处，文件树是「干活时的地图」。
- **为什么默认落在对话目录 / 桌面？** 用户展开树时**期望立刻看到当前在聊的那个项目**，不想每次手动找路径；若这条对话还没绑定目录，**桌面**是最稳妥的「人人都有、东西最多」的起点，避免空树。
- **为什么要搜索（名 + 内容）？** 大目录里靠手翻太慢。**按名**找「那个文件叫什么」，**按内容**找「哪个文件里写了这串关键字」——这是定位文件的两种真实诉求。
- **为什么要系统文件选择器切目录？** 用户想看的目录不一定是当前对话目录。借**操作系统自己的目录选择界面**选一个新目录当树根，符合用户已有的桌面操作习惯，零学习成本。
- **为什么图标要醒目且类型间可区分？** 图标是「不读字也能认出文件种类」的最快通道；只有每种类型都足够醒目、彼此用不同字形 / 配色拉开差距，用户扫一眼才能瞬间区分代码 / 图片 / 配置 / 文档 / 锁文件，而不是看到一片长得差不多的灰图标。
- **为什么要右键菜单？** 看清结构后，用户的下一步真实诉求是「就地动手」——在某目录下新建文件 / 文件夹、重命名、剪切复制粘贴搬运、在 Finder 里定位、复制路径去别处用、把某个文件 / 目录甩进当前对话让 agent 处理。每次都跳出去用别的工具做这些太慢；右键菜单把这些高频动作收在文件所在的地方。
- **为什么要对外开放为公共能力？** 目录树不该只服务「自己」。把它做成「**喂给它一个目录就能展示**」的可复用能力，后续对话侧选目录 / 点对话联动展示，都直接复用同一棵树，不重复造。

## 2. 范围

### 做

- **① 默认树根落点**：目录树展开时自动决定树根——当前对话**已选工作目录**则以该目录为根；**未选目录**则以**桌面（Desktop）**为根。
- **② 树的展开 / 收起 / 选中**：从树根起逐层列出文件夹与文件；点文件夹展开 / 收起其子层；点文件将其标为选中。多层嵌套可逐层展开。
- **③ 顶部工具按钮 · 搜索**：目录树顶部有搜索入口，支持**按文件名**搜与**按文件内容关键字**搜；命中结果以列表呈现并可定位 / 展示，命中处高亮。覆盖搜索的输入 / 结果 / 高亮 / 空结果 / 搜索中 / 清空退出全态。
- **④ 顶部工具按钮 · 切换目录**：目录树顶部有按钮可**打开操作系统的目录选择界面**；用户选定一个新目录后，目录树**改为以该新目录为树根**。覆盖取消选择 / 选了无权限或不存在目录的分叉。
- **⑤ 文件图标（醒目可区分）**：树上每个文件 / 文件夹都有对应图标，**每种文件类型有清晰可区分的专属图标——不同字形 / 配色，足够醒目，一眼能分辨代码 / 图片 / 配置 / 文档 / 锁文件等**；文件夹有**展开 / 收起两态**图标；未识别类型有通用兜底图标。
- **⑥ 右键上下文菜单（三套，按右键目标区分）**：右键唤起一个**下拉浮层**，弹在点击位置、优先向左下展开，贴近窗口下 / 右边界时翻转到左上（避免溢出）。三套菜单：
  - **A · 空白区（树空白处右键）**：新建文件 / 新建文件夹 / 粘贴（剪贴板有内容时启用）/ 在 Finder 中显示 / 在文件中查找 / 复制路径 / 复制相对路径。
  - **B · 目录行右键**：新建文件 / 新建文件夹 / 粘贴（同上条件）/ 在 Finder 中显示 / 复制路径 / 复制相对路径 / 剪切 / 复制 / 重命名 / 将文件添加到聊天。
  - **C · 文件行右键**：新建文件 / 在 Finder 中显示 / 在文件中查找 / 复制路径 / 复制相对路径 / 剪切 / 复制 / 重命名 / 将文件添加到聊天。
  - **差异（严格）**：「在文件中查找」只在 空白 + 文件，**目录没有**；「粘贴」只在 空白 + 目录（文件菜单无粘贴）；剪切 / 复制 / 重命名 / 将文件添加到聊天只在 目录 + 文件。
  - **各项行为（WHAT 层）**：
    - **新建文件 / 新建文件夹**：在目标目录下创建，交互为**树内内联输入**（就地出现可编辑新行，回车确认、Esc 取消），创建后刷新该层。
    - **重命名**：**树内内联**（原行变输入框），回车确认 / Esc 取消；重名或非法名给错误提示。
    - **剪切 / 复制 / 粘贴**：剪切 / 复制把目标放入剪贴板态；粘贴到目标目录 = 剪切→移动、复制→拷贝；粘贴项仅当剪贴板有内容时启用。
    - **在 Finder 中显示**：在操作系统文件管理器中定位该文件 / 目录（**桌面 only 能力门**，非桌面禁用）。
    - **在文件中查找**：在该文件 / 当前树根范围内**按内容搜索**（复用按内容搜索能力，接已有按内容搜索屏）。
    - **复制路径 / 复制相对路径**：把绝对路径 / 相对树根路径写入剪贴板。
    - **将文件添加到聊天**：把所选**文件**（文件引用）或**目录**（目录引用）作为附件引用加入当前对话的输入框（composer）——这是与对话模块的**联动**。
- **⑦ 全状态**：上述每屏的默认 / hover / 选中 / 加载 / 空 / 错误 / 离线等全态，含右键菜单的弹出 / 定位翻转 / 各项禁用态、内联新建 / 重命名态。
- **⑧ 目录树能力对外开放为公共能力**：这套「展示某目录的树 + 维护其树根 / 展开 / 选中状态 + 搜索 + 选目录」的能力**可被对话侧复用**，且**接受「外部指定的目录」作为输入**（外部传入要展示哪个目录，树就以它为根）。本需求只做产品层表述，**不定义任何接口形态**（那是架构师的事）。
- **平台**：**桌面 only**。

### 不做（防范围蔓延）

- **不重定义壳行为**：目录树 toggle（顶栏，默认收起）、按工作区记忆宽度（默认 280 / min 220 / max 500）、需有 active workspace 才可用、相邻手柄拖拽——全部沿用壳子 `2026-06-28-shell`，本需求一概不改、不重写。
- **不做文件内容预览面板的富展示**：本需求的「选中文件」只表达「在树上被选中 / 可定位」这一态；把文件内容渲染成可读视图（代码高亮 / diff / 图片预览等）**属右侧边栏「文件」页签**（壳子 §7.d.25），不在目录树里做。
- **不做拖拽排序 / 拖拽移动**：树内拖拽搬移文件 deferred；搬移仅经剪切→粘贴完成。
- **不做对话侧「选目录」「点对话联动」的具体交互**：本需求只把目录树能力**开放出去**并声明「接受外部目录输入」；对话侧怎么调它、在哪触发，属后续对话侧需求。
- **不做多目录树根 / 收藏夹 / 历史目录列表**：一次只显示一个树根。
- **不做移动 / 浏览器紧凑态**：deferred。

## 3. 流程（端到端）

> 每态有入口、有出口，无死胡同。

- **展开目录树 → 定位默认根**：用户点顶栏目录树 toggle 展开目录树（壳行为）→ 系统判定树根：当前对话**已选工作目录**则以该目录为根并列出其首层；**未选目录**则以**桌面**为根并列出首层。出口 = 可展开子目录 / 选中文件 / 搜索 / 切目录。
- **展开 / 收起子目录**：点某文件夹 → 列出其子层（文件夹在前或按既定排序），文件夹图标转为「展开态」；再点 → 收起子层、图标转「收起态」。可逐层深入多层。子目录加载期间该节点显**加载态**。
- **选中文件**：点某文件 → 该文件标为选中（行高亮）；同一时刻只一个选中项。出口 = 选中态供后续「在右侧边栏文件页签打开」复用（本需求不渲染预览）。
- **按名搜索**：点顶部搜索入口 → 出现搜索输入 → 用户输入关键字、选「按文件名」→ 系统在当前树根范围内匹配文件 / 文件夹名 → 命中以结果列表呈现、关键字片段高亮；点某条结果 → 在树上定位 / 展示该项。搜索中显**搜索中态**；无命中显**空结果态**；清空输入或退出搜索 → 回到普通树态。
- **按内容搜索**：搜索输入下选「按文件内容关键字」→ 系统在当前树根范围内搜文件内容 → 命中以结果列表呈现（标明命中文件，关键字高亮）→ 点某条结果 → 定位 / 展示该文件。搜索中 / 空结果 / 清空退出同上。
- **切换目录**：点顶部「切换目录」按钮 → 打开**操作系统的目录选择界面** → 用户选定新目录 → 目录树改为以新目录为树根、列出其首层；进入前的展开 / 选中态按新根重置。
  - **分叉 · 取消选择**：用户在系统选择界面点取消 → 不改变当前树根，目录树保持原样。
  - **分叉 · 无权限 / 不存在**：选中的目录无访问权限或已不存在 → 目录树显**错误态**（说明无法打开该目录 + 可重试或重新选目录），不改变也不清空原有可用树根的能力。
- **分叉 · 空目录**：树根或某子目录下无任何条目 → 该层显**空态**（如「此目录为空」）。
- **分叉 · 加载**：列目录 / 搜索期间显对应**加载 / 搜索中态**。
- **分叉 · 离线主机**：当前主机离线 / 失联 → 目录树显**离线态**（说明需主机在线才能浏览文件 + 主机恢复后可重试），不残留半截数据。
- **右键唤起菜单 → 选项 → 各自效果**：在树空白处 / 目录行 / 文件行右键 → 弹出对应的 A / B / C 下拉浮层，弹在点击位置、优先向左下展开；贴近窗口下 / 右边界时翻转向左上（不溢出）。点某项执行其效果：
  - **新建文件 / 新建文件夹** → 目标目录下出现内联可编辑新行 → 回车确认（创建并刷新该层）/ Esc 取消（不创建）。**分叉 · 重名冲突 / 非法名** → 内联行显错误提示，不关闭、不创建，待改正或取消。**分叉 · 无权限** → 显错误提示，创建失败、原树不变。
  - **重命名** → 原行变内联输入框 → 回车确认 / Esc 取消。**分叉 · 重名 / 非法名 / 无权限** → 行内错误提示，不应用改名。
  - **剪切 / 复制** → 目标进入剪贴板态（剪切项可呈待移动视觉）。
  - **粘贴** → 把剪贴板项放入目标目录（剪切→移动、复制→拷贝）并刷新该层。**分叉 · 剪贴板空** → 粘贴项禁用、不可点。**分叉 · 重名 / 无权限** → 显错误提示，原树不变。
  - **在 Finder 中显示** → 在系统文件管理器定位该项。**分叉 · 非桌面环境** → 该项禁用（能力门不满足）。
  - **在文件中查找** → 切到按内容搜索（接 sFT5），范围为该文件 / 当前树根。
  - **复制路径 / 复制相对路径** → 绝对 / 相对树根路径写入剪贴板（无可见副作用，可加轻提示）。
  - **将文件添加到聊天** → 把所选文件 / 目录作为引用加入当前对话 composer。**分叉 · 无活跃对话** → 该项禁用（无可加入的 composer）。
  - **菜单出口**：点任一项后菜单关闭并执行；点菜单外 / Esc → 关闭菜单、不执行、回到普通树态。
- **公共能力复用（后续衔接，本需求只声明）**：当外部（对话侧）传入「要展示的目录」时，目录树以该目录为根展示，复用同一套展开 / 选中 / 搜索 / 切目录行为——本需求保证该能力**接受外部目录输入**，具体由谁触发属后续。

## 4. 屏与全状态

> 逐屏对应 [ui.html](./ui.html) 锚点 `sFT*`（与 UI 设计师约定：**sFT 前缀，从 sFT1 起**）。每屏完整交互态以 ui.html 逐屏「交互注解块」（布局 / 状态 / 右键菜单 / 点击效果）为准。布局维度统一：**桌面 only；移动 / 浏览器紧凑态 deferred**。

- **sFT1 目录树 · 默认树态（落默认根）** `ui.html#sFT1`：目录树展开后的落地态——顶部工具条（含搜索入口 + 切换目录按钮）+ 树根行 + 树根首层条目（文件夹 / 文件，各带类型图标）。注解须区分两种默认根来源：**对话已选工作目录为根** 与 **未选目录→桌面为根**。关键态：每条目有按类型区分的图标、文件夹呈「收起态」图标；行 默认 / hover / 选中（选中行高亮）；顶部两个工具按钮 默认 / hover / 按下。
- **sFT2 目录树 · 多层展开态** `ui.html#sFT2`：多个文件夹逐层展开、嵌套缩进可见——展开的文件夹呈「展开态」图标、其子层条目缩进列出。关键态：逐层缩进、展开 / 收起两态文件夹图标对照、深层节点可继续展开；某节点**加载态**（子目录列取中）。
- **sFT3 目录树 · 文件选中态** `ui.html#sFT3`：某文件被点选 → 该行高亮为选中；同时刻仅一个选中项。关键态：选中行视觉、hover 与选中区分；点击效果注明「选中态供后续右侧边栏文件页签打开复用，本需求不渲染预览」。
- **sFT4 目录树 · 按文件名搜索态** `ui.html#sFT4`：搜索输入展开 + 搜索范围切到「按文件名」+ 命中结果列表（文件 / 文件夹名，关键字片段高亮）。关键态：输入 默认 / 聚焦；结果行 默认 / hover / 点选定位；**搜索中态**（进度指示）；点结果在树上定位 / 展示。
- **sFT5 目录树 · 按文件内容搜索态** `ui.html#sFT5`：搜索范围切到「按文件内容关键字」+ 命中结果列表（标明命中文件，关键字高亮）。关键态：范围在「名 / 内容」间切换的入口；结果行点选定位到文件；**搜索中态**。
- **sFT6 目录树 · 空 / 加载 / 错误 / 离线态** `ui.html#sFT6`：聚合呈现四种非常规态——**空态**（空目录 / 搜索无命中，文案区分两者）、**加载态**（列目录 / 搜索中）、**错误态**（所选目录无权限 / 不存在，含重试或重选目录入口）、**离线态**（主机离线，含「需主机在线 + 可重试」说明）。关键态：每态都有明确的出口（重试 / 重选目录 / 清空搜索 / 等待主机恢复），无死胡同。
- **sFT7 目录树 · 切换目录（系统选择器入口）态** `ui.html#sFT7`：点顶部「切换目录」按钮 → 触发**操作系统目录选择界面**的入口态（系统界面本身由 OS 绘制，框内只画 Helm 侧的触发按钮与触发后的等待 / 回填表现）。关键态：按钮 默认 / hover / 按下 / 触发中；**取消选择**回到原树态；**选定新目录**树根切换并列首层；**选了无权限 / 不存在**接 sFT6 错误态。
- **sFT8 目录树 · 右键上下文菜单态** `ui.html#sFT8`：右键唤起的下拉浮层，呈现三套菜单 + 定位翻转 + 内联新建 / 重命名 / 删除确认态。关键态：**A 空白菜单 / B 目录菜单 / C 文件菜单**三套并列对照，每套项目齐全且差异如实（在文件中查找 = 空白+文件；粘贴 = 空白+目录；剪切/复制/重命名/将文件添加到聊天/删除 = 目录+文件）；**定位**——弹在点击位置、优先向左下，贴近窗口下 / 右边界翻转向左上；**条件禁用态**——粘贴（剪贴板空时禁用）、在 Finder 中显示（非桌面禁用）、将文件添加到聊天（无活跃对话禁用）；**内联新建态**（目标层就地可编辑新行，回车 / Esc）；**内联重命名态**（原行变输入框，回车 / Esc，重名 / 非法名行内错误提示）；**删除**为破坏性操作，点了先确认再执行；菜单项 默认 / hover / 禁用，菜单关闭出口（点项 / 点外 / Esc）。

**全态交互聚焦**：每屏覆盖 默认 / hover / 选中 / 聚焦 / 加载（含节点级加载）/ 搜索中 / 空（空目录 vs 无命中）/ 错误（无权限 / 不存在）/ 离线 / 浅深主题。**右键菜单**：目录树**提供右键上下文菜单**（三套 A 空白 / B 目录 / C 文件 + 定位翻转 + 内联新建 / 重命名 / 删除确认），完整态见 **sFT8**；各屏注解块的右键菜单维度统一指向 **sFT8**（不再写「无」）。本轮**含删除项**（仅目录 / 文件菜单；delete 为破坏性操作，点了先确认）。

## 5. 边界与依赖

### 与既有设计的关系

- **建立在壳子之上**：本需求填的是壳子 `2026-06-28-shell` §7.e.26 标注的目录树空容器。目录树的 toggle / 默认收起 / 按工作区记忆宽度（280 / 220 / 500）/ 需 active workspace / 拖拽改宽，**全部是壳行为，本需求沿用不改**。
- **与「对话 / 工作区选中目录」的关系**：默认树根取自「当前对话的工作目录」；该「对话选目录」能力**本需求不实现**，本需求只**消费**它（有则用、无则落桌面）。反向地，本需求把目录树做成**接受外部目录输入的公共能力**，为后续「对话选目录」「点对话联动展示该对话目录」留好复用面——但触发方与触发交互属后续需求。
- **与右侧边栏「文件」页签的关系**：目录树负责「定位 + 选中」，文件内容的可读预览属右侧边栏文件页签（壳子 §7.d.25），二者分工，本需求不越界做预览。

### 平台与能力门（用 WHAT 描述，不写 RPC / 接口名）

- **桌面 only**；移动 / 浏览器紧凑态 deferred。
- **能力门 · 列目录**：依赖「主机能列出某目录下的文件与文件夹」的能力。该能力不可用 / 主机离线时，目录树走加载 / 错误 / 离线态，不崩。
- **能力门 · 文件内容搜索**：依赖「主机能在某目录范围内按内容关键字搜文件」的能力。不可用时按内容搜索走错误 / 空态。
- **能力门 · 客户端目录选择**：依赖「客户端 / 操作系统能弹出目录选择界面让用户选一个目录」的能力。
- 以上三项均为**能力门**：能力在则功能可用，能力缺则相应路径给出可恢复的提示态，**不写降级版另一套实现**。

## 6. 验收标准（逐条可判定 · 能 / 否）

**默认树根（硬性需求 1）**

1. 目录树展开时，若**当前对话已选工作目录**，树根**能**自动显示为该对话选择的目录，并列出其首层条目。
2. 目录树展开时，若**当前对话未选目录**，树根**能**自动显示为**桌面（Desktop）**目录，并列出其首层条目。

**展开 / 收起 / 选中**

3. **能**点文件夹展开其子层、再点收起，文件夹图标在「展开态 / 收起态」间相应切换；**能**逐层深入多层嵌套。
4. **能**点选一个文件使其行高亮为选中态，且同一时刻**仅一个**选中项。

**搜索（硬性需求 2）**

5. 目录树顶部**有**搜索入口；**能**按**文件名**搜索并以结果列表呈现命中、关键字片段高亮。
6. **能**按**文件内容关键字**搜索并以结果列表呈现命中（标明命中文件）、关键字高亮。
7. **能**点搜索结果定位 / 展示到对应文件或文件夹。
8. 搜索具备**搜索中态**、**无命中空结果态**，且**能**清空输入 / 退出搜索回到普通树态。

**切换目录（硬性需求 3）**

9. 目录树顶部**有**「切换目录」按钮，点击**能**打开操作系统的目录选择界面。
10. 在系统界面选定一个新目录后，目录树**能**改为以该新目录为树根并列出其首层。
11. 在系统界面**取消选择**时，当前树根**不**改变、目录树保持原样。
12. 选了**无权限 / 不存在**的目录时，目录树**能**显示可恢复的错误态（可重试 / 重选目录），且不无声丢失原有可用能力。

**文件图标 · 醒目可区分（董事长改动 1）**

13. 树上**每个**文件与文件夹都**有**对应图标；**每种文件类型有专属图标**，类型之间用**不同字形 / 配色**拉开差距、**足够醒目**，**能**一眼分辨代码 / 图片 / 配置 / 文档 / 锁文件等常见类型；文件夹**有**展开 / 收起两态图标；未识别类型**有**通用兜底图标。

**右键上下文菜单 · 三套（董事长改动 2）**

13a. 在**树空白处**右键**能**弹出菜单 A，且项目齐全：新建文件 / 新建文件夹 / 粘贴 / 在 Finder 中显示 / 在文件中查找 / 复制路径 / 复制相对路径。
13b. 在**目录行**右键**能**弹出菜单 B，且项目齐全：新建文件 / 新建文件夹 / 粘贴 / 在 Finder 中显示 / 复制路径 / 复制相对路径 / 剪切 / 复制 / 重命名 / 将文件添加到聊天。
13c. 在**文件行**右键**能**弹出菜单 C，且项目齐全：新建文件 / 在 Finder 中显示 / 在文件中查找 / 复制路径 / 复制相对路径 / 剪切 / 复制 / 重命名 / 将文件添加到聊天。
13d. 差异**严格成立**：「在文件中查找」**仅**出现在 空白 + 文件（目录**无**）；「粘贴」**仅**出现在 空白 + 目录（文件**无**）；剪切 / 复制 / 重命名 / 将文件添加到聊天 / 删除**仅**出现在 目录 + 文件。
13e. 菜单弹在**点击位置**、优先向左下展开；贴近窗口**下 / 右边界**时**能**翻转向左上、不溢出窗口。
13f. 菜单**含删除项**（仅目录 / 文件菜单；空白菜单无），delete 为破坏性操作，点了先弹确认，再执行。

**右键各项行为与联动（董事长改动 3）**

13g. **新建文件 / 新建文件夹**：**能**在目标目录下以**树内内联输入**创建（就地可编辑新行，回车确认、Esc 取消），创建后**能**刷新该层。
13h. **重命名**：**能**以**树内内联输入**（原行变输入框）改名，回车确认 / Esc 取消；**重名或非法名能给错误提示**且不应用。
13i. **剪切 / 复制 / 粘贴**：剪切 / 复制**能**把目标放入剪贴板态；粘贴**能**按「剪切→移动、复制→拷贝」放入目标目录；**剪贴板为空时粘贴项禁用**、不可点。
13j. **在 Finder 中显示**：桌面环境下**能**在系统文件管理器定位该文件 / 目录；**非桌面环境下该项禁用**（桌面 only 能力门）。
13k. **在文件中查找**：点击**能**切到按内容搜索（接 sFT5），范围为该文件 / 当前树根。
13l. **复制路径 / 复制相对路径**：**能**分别把绝对路径 / 相对树根路径写入剪贴板。
13m. **将文件添加到聊天**：**能**把所选**文件**（文件引用）或**目录**（目录引用）作为附件引用加入当前对话 composer；**无活跃对话时该项禁用**。

**公共能力对外开放（硬性需求 5）**

14. 文档明确：目录树的「展示某目录的树 + 树根 / 展开 / 选中状态 + 搜索 + 选目录」是一项**对外可复用的公共能力**，**接受「外部指定的目录」作为输入**（外部传入即以该目录为根展示），可供后续对话侧复用。
15. 该条**仅以 WHAT 表述**：requirement 全文**不**出现任何函数名 / 接口名 / 文件名 / 协议名（接口形态归架构师）。

**全状态**

16. ui.html 逐屏注解块**齐全可判定**地覆盖：默认 / hover / 选中 / 聚焦 / 节点级加载 / 搜索中 / 空（空目录与无命中区分）/ 错误（无权限 / 不存在）/ 离线，且每个非常规态都有定义的出口（重试 / 重选 / 清空 / 等待主机恢复），无死胡同。
17. 主机**离线**时目录树显示离线态、不残留半截数据，主机恢复后**能**重试。

**边界**

18. 文档明确本需求**不重定义**壳的目录树 toggle / 宽度记忆（280 / 220 / 500）/ active workspace 门 / 拖拽，均沿用壳子。
