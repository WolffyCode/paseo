## 三、B 流程打通逐条（找死胡同/断链）

**B1 主流程** — 通过。展开（壳 toggle）→ 默认根判定（对话目录 / 桌面两分支各有 sFT1 框）→ 展开收起（sFT2，含节点级加载/失败内联重试）→ 选中（sFT3 单选互斥）→ 名搜（sFT4）→ 内容搜（sFT5）→ 切目录（sFT7）。每环出口明确（requirement §3 48–59 行 + ui.html 各屏点击效果）。

**B2 非常规态入口+出口（无死胡同）** — 通过。sFT6 「态机入口/出口」块逐态列：

- 加载：入口=首开/切换/刷新/索引，出口=树/空/错误。
- 空目录：入口=无条目，出口=切换目录 / 刷新。
- 搜索无命中：入口=结果 0，出口=改词/切范围/清空退出（且明确 ≠ 空目录）。
- 错误（无权限/不存在）：入口=读取失败，出口=重试→树 / 重选目录→新根。
- 离线：入口=主机断连，出口=重试连接 / 自动重连→恢复上次树；工具条禁用、不残留半截数据（验收 17）。
- 取消（sFT7 分叉3）：回原态，根/展开/选中全保持，无副作用。

**B3 跨屏衔接无 orphan/断链** — 通过。sFT4/sFT5 结果点选 → sFT3 选中（明写「选中该文件（sFT3）+ 树定位」）。sFT7 选无权限 → sFT6 错误（明写「接 sFT6 错误态，保留切换前根作回退基线」）。sFT2 节点加载失败 → sFT6 错误语义。sFT6 各态出口均指向有效目标（sFT7 / 树态 / 普通树）。无孤立锚点。

**B4 与壳子边界清晰** — 通过。requirement §2「不做」+ §5、architecture §1/§4 反复声明：toggle/默认收起/宽度记忆(280/220/500)/active-workspace 门/拖拽 全沿用壳 `2026-06-28-shell` §7.e.26（已核对 shell requirement 26/28/29/34/39 行确认目录树文件为壳标注的空容器），本需求不重定义。与右侧边栏「文件」页签分工：目录树负责定位+选中，富预览归文件页签（壳 §7.d.25），无重叠无遗漏。
