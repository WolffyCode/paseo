交互注解
点击效果（每态出口）
  1. 1
    空目录「切换目录」：打开系统选择器换根（sFT7）。出口 = 选定非空目录 → 树态。
  2. 2
    搜索无命中：无动作钮；改关键字 / 切名内容范围即重搜（出口回结果或树）。清空 × 回普通树。与空目录的区别：此态仍在搜索条下、根目录其实有内容。
  3. 3
    加载态：纯骨架无可点；出口 = 树就绪→树态 / 空目录→空态 / 失败→错误态。
  4. 4
    错误「重试」：重拉该目录（成功→树，失败→留错误）；「重选目录」 = 开系统选择器换根（sFT7）。
  5. 5
    离线「重试连接」：触发壳层重连；连上后自动恢复上次树与选中。工具条 4 钮在离线时置灰禁用。
布局 + 状态（态机入口/出口）
布局
各态共用面板几何，仅替换主体。空/无命中/错误/离线 = 居中图标 + 标题 + 说明（+ 动作钮）；加载 = 骨架行。紧凑态 deferred。
加载
入口：首开 / 切换目录 / 刷新 / 大目录索引。出口：树 / 空 / 错误。
空目录
入口：目标目录无任何条目。出口：切换目录 / 新增文件后刷新。
搜索无命中
入口：搜索结果 0（名或内容）。出口：改词 / 切范围 / 清空退出搜索。≠ 空目录。
错误
入口：无权限 / 不存在 / 读取失败。出口：重试成功→树 / 重选目录→新根。
离线
入口：主机断连。出口：重试连接 / 自动重连→恢复上次树。工具条禁用。
右键菜单
见 sFT8。空目录/无命中态主体无行 → 仍可在空白区右键 = A 套（可新建文件/夹/粘贴，新建后退出空态）；加载/错误/离线态主体不可右键（无内容 / 失能）。

交互注解
① 布局（浮层尺寸 / 分组 / 定位与翻转）
平台
桌面 only（右键 = 鼠标 contextmenu）。紧凑 / 手机态 deferred（无右键，后续以长按菜单替代）。
浮层
白底卡，圆角 10、阴影 0 8px 24px；宽约 232；项行高 30、圆角 6、菜单项纯文字无前置图标，右侧灰提示（如「剪贴板空」「仅桌面」「无对话」）。分隔线把：新建组 / 剪贴板组（剪切·复制·重命名·粘贴·删除）/ 路径与显示组 / 加入聊天，四组分开。
定位
目录树在窗口右侧 → 菜单一律向左展开。纵向默认向下：菜单右上角对齐右键点位，向下 + 左铺开（= 左下）。
边界翻转
仅纵向翻转：当左下方在窗口内放不下（点位贴近下边界）→ 翻到点位上方，菜单右下角对齐点位，向上 + 左铺开（= 左上）。横向始终向左，不向右翻。始终保证菜单完整可见、不溢出窗口。
右键行
被右键的行保持高亮（#eaeef2）直到菜单关闭；右键不改变已有的文件选中态。空白区右键无行高亮。
② 状态（菜单项 默认/hover/禁用 · 内联 聚焦/校验错误）
默认
项文字深灰、左图标灰。
hover
项底 #f6f8fa，图标转深灰；键盘 ↑↓ 高亮同效，Enter 触发。
禁用
置灰 .5 不可点：粘贴（剪贴板空）；在 Finder 中显示（非桌面端 / 无原生能力）；将文件添加到聊天（无活跃对话）；删除（破坏性，需先确认）。
内联聚焦
输入框蓝边 + 3px 蓝环；新建 = 空+光标，重命名 = 主名段选中（扩展名留）。
校验错误
重名 / 非法字符 / 空名 → 输入框红边 + 行下红字（如「已存在同名文件」）；Enter 拦截不提交，Esc 取消回原态。
提交
Enter 合法 → 写入并按序归位、选中新项；失焦默认提交（合法）/ 取消（空新建）。
③ 右键菜单（本屏主体 · 三套逐项 + 点击效果）
差异速记：「在文件中查找」= 空白 + 文件有、目录没有；「粘贴」= 空白 + 目录有、文件没有；剪切 / 复制 / 重命名 / 将文件添加到聊天 / 删除 = 目录 + 文件有、空白没有。
A · 空白区
新建文件 → 在当前根内联新建一行；新建文件夹 → 内联新建文件夹；粘贴 → 把剪贴板项移动（剪切来）/ 拷贝（复制来）到根，剪贴板空时置灰 ‖ 在 Finder 中显示 → 系统定位根目录；在文件中查找 → 打开内容搜索（→ sFT5）；复制路径 → 绝对路径入系统剪贴板；复制相对路径 → 相对根路径入剪贴板。
B · 目录行
新建文件 / 新建文件夹 → 在该目录内内联新建（自动展开该目录）；粘贴 → 移动/拷贝到该目录（条件同上） ‖ 剪切 / 复制 → 把该目录引用入剪贴板（剪切的目录半透明标记）；重命名 → 该行内联重命名 ‖ 在 Finder 中显示 → 系统定位该目录；复制路径 / 复制相对路径 → 写剪贴板 ‖ 将文件添加到聊天 → 把该目录引用加入当前对话 composer（与对话模块联动），无活跃对话时置灰。
C · 文件行
新建文件 → 在该文件所在目录内联新建 ‖ 剪切 / 复制 → 文件引用入剪贴板；重命名 → 内联重命名（主名段选中） ‖ 在 Finder 中显示 → 系统定位该文件；在文件中查找 → 打开内容搜索（→ sFT5）；复制路径 / 复制相对路径 → 写剪贴板 ‖ 将文件添加到聊天 → 把该文件引用加入当前对话 composer（与对话模块联动），无活跃对话时置灰。
④ 点击效果（汇总 · 出口）
  1. 1
    新建文件 / 新建文件夹 → 目标位置插入内联输入行（聚焦 + 光标）；Enter 合法写入→选中新项，重名→校验错误，Esc→取消。
  2. 2
    重命名 → 原行变内联输入框（主名选中）；同上提交/校验/取消。
  3. 3
    剪切 / 复制 → 文件/目录引用入剪贴板（剪切项后续粘贴为移动并清剪贴板，复制为拷贝可重复粘贴）；剪切项树中半透明标记。
  4. 4
    粘贴 → 把剪贴板项移动 / 拷贝到目标（空白=根、目录行=该目录）；剪贴板空时该项置灰不可点。
  5. 5
    在 Finder 中显示 → 调系统在文件管理器定位该项；非桌面端置灰。
  6. 6
    在文件中查找 → 打开/切到内容搜索（sFT5），以该目录为范围（文件项=其所在目录/根）。
  7. 7
    复制路径 / 复制相对路径 → 绝对 / 相对根路径写入系统剪贴板（短暂 toast 由壳层提供）。
  8. 8
    将文件添加到聊天 → 把文件 / 目录引用加入当前对话 composer（与对话模块联动）；无活跃对话时置灰。
  9. 9
    删除 → 先弹确认；确认后删除文件 / 目录并刷新该层。取消则不执行。
  10. 10
    关闭：点菜单外 / Esc / 选完一项 → 浮层关闭，右键行高亮复原。
