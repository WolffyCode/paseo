## 1. 目标 & 用户价值

**一句话目标**：把对话页右侧的**右侧侧边栏空容器**填成一个**多页签工作面板**——展开后默认落在**启动器列表**，可开五类页签（对话 / 浏览器 / 代码审核 / 终端 / 文件），具备 **Codex 式 tab 头（图标+文字 · 活跃胶囊高亮 · 末尾 + · 右上 ⤢）** 的完整页签管理（新建 / 去重 / 关闭 / 调序 / 右键 / 放大缩小 / 关全部回启动器）；**本轮把「文件」与「浏览器」两类页签做到全态全深度**——**文件页签做成类 VSCode 的查看+编辑面**（代码高亮编辑、Markdown 编辑/预览双态、图片只读、脏标记/保存/关闭确认/外部变更冲突），**浏览器页签全量对齐 Codex**（地址栏导航、设备工具条、隔离沙箱、截图+标注、标注截图加入对话 composer）；并**承接对话页「文档地址→文件页签」的跳转打开**、**消费目录树输出的「选中文件」并与目录树双向联动**。其余三类（对话 / 代码审核 / 终端）本轮**只在框架层声明类型与实例规则、标「后续」**，不设计内部。

**用户为什么需要它**：

- **为什么要工作面板？** 用户在对话里指挥 agent 干活，干完需要一个**固定的操作台**动手看东西——审 agent 改了什么、跑终端看输出、开浏览器看页面效果、翻文件看/改内容、在侧边另起一条子对话。空容器毫无用处；工作面板是「对话之外，动手看东西的地方」。
- **为什么是这五类页签？** 用户在对话之外的「动手看东西」诉求恰好收敛成五种彼此独立、不重叠的操作台：**对话**（侧边再起一条会话/子对话）、**浏览器**（看 agent 建的页面效果 + 把问题精确指给它）、**代码审核**（审 agent 的改动、Stage/Revert/行评论）、**终端**（跑命令看输出）、**文件**（查看/编辑某个具体文件）。五类一次性声明为完整框架，用户对「右边能干什么」一眼有全貌，也不必为后续新增类型重构面板骨架。
- **为什么本轮只做「文件」+「浏览器」两类内部？** 框架（所有页签挂靠的骨架）必须先立牢；内容分批填。**文件页签是「目录树 + 对话跳转」的共同落点**——两个兄弟模块都把「文件富预览/编辑的账」记到这个页签（file-tree §2「不做」明写「文件内容富预览属右侧边栏文件页签」；conversation-page §2「文档地址跳右栏的目标内容不在本需求」）——不做就**双向断链**，最该先兑现。**浏览器页签是一条独立且完整的闭环**（agent 建页面→人看效果→截图圈重点→写反馈→喂回 agent），价值自足、可一次做透。**代码审核 / 终端 / 对话的内部是可分离的重基建**（diff 引擎 + Stage/Revert 语义 / 终端会话流 / 侧边对话），本轮先立框架、标后续，避免在没摸清真实用法前一次铺开、建错返工（呼应 codepilot-layout「先立形、再填细节」的分阶段铁律）。
- **为什么文件页签要可编辑（不再是只读）？** 董事长否决了 v1「只读预览」。用户在审改代码的工作流里，**常要就地改一两处**——修个错别字、调一行配置、补段注释、写点 Markdown——为这点小改动跳出去开别的编辑器太慢、丢现场。**类 VSCode 的「查看+语法高亮+编辑」把「看文件」和「改文件」收在同一个落点**。**Markdown 做「编辑/预览」双态**因为 md 既是「读文档」也是「写文档」两种真实诉求。**图片只读**因为图片没有就地编辑诉求（编辑图片是另一个产品，YAGNI）。
- **为什么浏览器要全量对齐 Codex？** 用户对 in-app 浏览器的核心诉求**不是「又一个浏览器」**，而是**「把看到的问题精确地指给 agent」**。Codex 已把「看页面→截图→圈选某元素/某区域→写粒度样式反馈→送进对话 composer→交给 agent」这条闭环打磨成熟。缺了「截图+标注+进 composer」这一环，浏览器只是个孤立预览窗、无法参与产品主循环。全量对齐是**采用成熟范式、避免自创半成品**。
- **为什么要 Codex 式 tab 头（胶囊高亮）而非蓝下划线？** 董事长指明 tab 头观感对齐 Codex：图标+文字页签、活跃页签**胶囊式高亮**、页签间细分隔、末尾 +、右上 ⤢。胶囊高亮比 v1 的蓝下划线更整体、更贴近参照产品的一眼观感。
- **为什么要放大缩小？** 文件编辑 / 浏览器页面有时需要**更大视野**细看细改：整面板放大占满对话区、单页签放大聚焦一处——都是真实的「看得更清、改得更稳」诉求。
- **为什么要承接对话跳转 + 消费目录树 + 与树双向联动？** 用户在对话里点了某文档地址、在目录树里选中某文件，期望**立刻在右边打开**；反过来，切到某个文件页签时，也期望目录树**自动定位到该文件所在处**，让「我在改哪个文件」在树里一眼可见。右侧侧边栏是这些跳转的**统一落点**，并与目录树**双向联动**——不承接、不联动，跳转就无处可去、目录树的「选中」就没有下文、「我在哪」就丢失。

## 2. 范围

> 董事长允许「页签框架全做 + 部分页签内容全做、其余页签只声明框架标后续」的分阶段切法（参照 codepilot-layout / v1 分阶段先例）。下方**做 / 不做逐条写死**，并对**深度切分**显式论证。

### 做

#### A. 页签框架能力（全做——这是五类页签挂靠的骨架，不能半建）

- **① 打开默认 = 启动器列表**：右侧侧边栏展开且**无任何已打开页签**时，落地态为**竖排启动器**；顶部**仅有 ⤢ 放大 + 收起**，**没有 tab 条、也没有「新选项卡 +」**。点某可用项 → 开对应类型页签、tab 条随之出现。**启动器呈现项 = 全部五类**（对话 / 浏览器 / 代码审核 / 终端 / 文件），其中**文件、浏览器为可用项**，**对话 / 代码审核 / 终端三行呈禁用 + 「后续」标**（呈现取向的论证见 §6·启动器呈现项）。
- **② 五类页签类型体系（框架层声明）**：面板可承载五类页签——**对话**（右栏侧边会话/子对话，本轮后续）、**浏览器**（本轮全做，Codex 对齐）、**代码审核**（工作区 diff · Stage/Revert/行评论，本轮后续）、**终端**（本轮后续）、**文件**（本轮全做，可编辑）。五类均在框架层声明并给出实例规则；**对话 / 代码审核 / 终端本轮不设计内部**。
- **③ 实例规则（产品写死）**：
  - **代码审核 = 单实例**：面板内只能存在一个代码审核页签；在已有代码审核页签时再次「打开代码审核」= **聚焦既有页签**、不新建第二个。
  - **对话 / 浏览器 / 终端 / 文件 = 多实例**：可同时存在多个同类页签（去重规则见 ④）。
  - v1「审查固定第一 / ✕ 置灰不可关」框架**作废**：新框架下**无常驻页签、无固定首位、无不可关页签**。
- **④ 多实例的去重与命名区分（产品写死）**：
  - **去重**：**文件页签按「同一文件只开一个」去重**——对同一文件重复打开 = 聚焦既有页签、不新开（详见 C）；**浏览器 / 对话 / 终端各实例相互独立、不去重**（可对同一 URL 开多个浏览器页签）；**代码审核受单实例规则**（③）。
  - **命名区分**：同类多个页签用各自内容区分标识——**文件 = 文件名**、**浏览器 = 页面标题（无标题时用 URL）**、**终端 = 会话序号或工作目录**（后续）、**对话 = 会话标题**（后续）、**代码审核 = 固定标识**（单实例，后续）；标识过长时**省略**（截断显示，完整标识可经悬浮提示获得）。
- **⑤ tab 头（Codex 观感对齐）**：tab 条上每个页签 = **图标 + 文字**；**活跃页签 = 胶囊式高亮**（非蓝下划线）；页签之间有**细分隔**；tab 条**末尾有「新选项卡 +」**；tab 条**右上有 ⤢ 放大 + 收起**。
- **⑥ 新选项卡 +（下拉）**：点 tab 条末尾「新选项卡 +」→ 弹**下拉**，呈现**全部五类**（文件 / 浏览器可用；对话 / 代码审核 / 终端禁用 + 「后续」标），各带快捷键提示；选一个可用项即在 tab 条追加对应类型页签并聚焦；**快捷键等价触发**（无需先点 +）。
- **⑦ 悬浮关闭 ✕**：页签**悬浮时**行尾浮出 ✕，点它关闭该页签。**所有已打开页签均可关**（关闭 = 仅布局层移除、可重开；有未保存改动的文件页签关闭前先弹确认，见 C）。新框架下**没有「不可关 / ✕ 置灰」的常驻页签**。
- **⑧ 拖拽调序**：页签可**左右拖拽调序**，拖动时显**放置指示线**；无固定首位约束，任意页签可拖到任意位置。
- **⑨ 页签右键菜单（3 项）**：在页签上右键 → **关闭页签 / 关闭其它 / 关闭全部**。
- **⑩ 放大缩小 ⤢**：
  - **整面板放大**：tab 条右侧 ⤢ → 右侧侧边栏**扩展占满对话区的空间**、**左栏保留**、**目录树按其自身显隐保留**；**还原 ⤡** 回到停靠态。
  - **单页签放大**：每个页签内容右上角有 ⤢ → **单独放大该页签内容**（文件 / 浏览器各自可放大），再 ⤡ 还原。
- **⑪ 关掉全部页签 → 回启动器默认态**：所有页签关闭后回到 ① 的启动器列表。**新框架下无常驻页签，「关全部」可真正回到裸启动器**（v1「审查常驻挡住出口」的问题随框架改写自然消解）。

#### B. 浏览器页签（全态全做 · Codex 全量对齐）

- **打开**：从启动器 / 新选项卡开浏览器 / 快捷键；新建浏览器页签默认落**「新标签（开始浏览）」空态**。
- **地址栏与导航**：**后退 ← / 前进 → / 刷新 ⟳ / URL 输入 + 前往**；URL 栏右侧 **⋯（更多）→ 设备工具条**（切换设备 / 响应式视口尺寸，测试不同屏宽）。
- **页面预览**：页签内**内嵌渲染网页**；**用户与 agent 共享同一渲染页面**（同一页面双方可见）。
- **隔离沙箱**：**不使用**常规浏览器配置 / cookie / 扩展 / 已登录会话 / 已有标签页（沙箱隔离）；登录类页面因此不可用——作为**约束/说明态**呈现（非报错）。
- **截图 + 标注模式（核心）**：进入标注模式 = **右上角按钮** 或 **快捷键**；标注模式下可**点选某元素**（选中一个 UI 组件）或 **Shift + 拖拽选一块区域**；捕获内容 = **批注文字 + 截图 + 元素上下文**。
- **粒度样式反馈**：批注输入框旁有**配置图标** → 给字体 / 文字 / 间距 / 颜色等更细的样式反馈，**发送前可在页面上直接预览**效果。
- **加入对话（联动）**：把「批注截图 + 元素上下文」**加入对话 composer**（作为引用/附件进输入框）→ 交给 agent。**本模块只负责「发起添加」这一步**（截图→标注→送入 composer）；**composer 如何渲染该附件归 conversation-page**；**需有活跃对话方可添加**（无活跃对话 → 该动作禁用，呼应 file-tree「将文件添加到聊天·无活跃对话禁用」同款门）。
- **右键菜单（6 项）**：后退 / 前进 / 刷新 / 复制链接 / 进入标注模式 / 在外部浏览器打开。
- **全态**：默认（地址栏+页面）/ 加载（导航中指示）/ 空（新标签「开始浏览」）/ 标注模式（选择叠层）/ 错误（页面加载失败 + 重试）/ 隔离说明（登录类不可用）/ 离线（见面板级）/ 浅深主题。

#### C. 文件页签（全态全做 · 类 VSCode 可编辑）

- **形态（按文件类型）**：
  - **代码 / 文本**（js / ts / java / txt 等）= 查看 + **语法高亮** + **编辑**。
  - **Markdown** = **编辑 / 查看（预览）双形态**可切换（页签内有「编辑 ⇄ 预览」切换）。
  - **图片** = **查看（不可编辑）**。
  - **未识别 / 二进制** = **只读兜底**（说明无法编辑）。
- **打开来源（三种）**：① **目录树点击文件**（消费 file-tree 输出的「选中文件」）；② **对话点文档地址**（承接 conversation-page 发起的跳转）；③ **启动器 / 新选项卡开文件**（无选中 → 空态「选择一个文件」）。**目录树点文件时若右侧侧边栏收起 → 顺带展开右栏**（沿用壳「展开右侧边栏」公共壳行为，本需求不新增布局原语）。
- **同一文件去重**：对**同一文件**重复打开 = **聚焦既有页签**、不新开；不同文件各一个页签、可多开。
- **切树根不删页签**：目录树切换树根（换目录）**不删除**已打开的文件页签。
- **页签 ↔ 树双向联动（钉死语义，见 §3.2.联动）**：切到 / 聚焦某文件页签 → **命令目录树定位到该文件**（reveal 或重根），语义按该文件与当前树根的关系三分支确定；反向，目录树选中文件 → 打开 / 聚焦对应文件页签。此联动是**命令 file-tree 公共能力执行定位**，本模块**不重画树**、不越界。
- **编辑必备态**：
  - **未保存脏标记**：文件被改动但未保存时，页签 / 标题区显**脏标记**（可见脏点）。
  - **保存交互**：有**保存动作**，并给**保存中 / 成功 / 失败**反馈；保存失败可重试。
  - **关闭未保存确认**：关闭有脏改动的文件页签前，先弹**确认**，三择一：**保存并关闭 / 放弃更改并关闭 / 取消（不关闭）**。
  - **外部文件变更冲突**：页签打开期间该文件在主机侧被**外部改动** → 弹**冲突提示**，给出口：**重载（放弃本地未保存改动、载入主机最新）/ 保留本地（忽略外部变更、以本地为准）/ 对比（并排看本地与主机最新）**。
- **右键菜单（三套，按内容区）**：
  - **代码 / 文本编辑区（9 项）**：剪切 / 复制 / 粘贴 / 全选 / 保存（无改动置灰）/ 还原此文件（非脏置灰 · 放弃未保存改动回到已存盘版本）/ 复制文件路径 / 在目录树中定位 / 在 Finder 中显示。
  - **Markdown 预览区（5 项）**：复制选中文本 / 复制文件路径 / 在目录树中定位 / 在 Finder 中显示 / 切到编辑。
  - **图片查看区（4 项）**：复制图片 / 复制文件路径 / 在目录树中定位 / 在 Finder 中显示。
  - **说明**：Markdown 编辑形态下右键 = 代码/文本编辑区 9 项（md 编辑即文本编辑；切到预览经页签内「编辑 ⇄ 预览」切换）。**目录树相关文件写操作（新建 / 重命名 / 删除 / 剪切复制粘贴文件等）归 file-tree 模块、不在本页签的任何右键里**（保持「不重画树」边界）。
- **全态**：默认（渲染内容）/ 编辑中 / 脏（未保存）/ 保存中·成功·失败 / 空（未选文件）/ 加载（读取）/ 错误（无法读取该文件 + 重试）/ 冲突（外部变更）/ 只读兜底（图片 / 二进制 / 未识别）/ 离线（见面板级）/ 浅深主题。
- **边界**：文件页签**不含目录树**（只消费选中 + 命令 reveal / 重根）。

#### D. 对话 / 代码审核 / 终端页签（仅框架层声明 · 内部标后续）

- **本轮只做**：在框架层**声明类型 + 实例规则**（代码审核单实例；对话 / 终端多实例），并在**启动器 / 新选项卡下拉**中以**禁用 + 「后续」标**呈现（诚实展示路线图、不产生死胡同）。
- **本轮不做**：三者的**内部**——对话（侧边会话/子对话）、代码审核（工作区 diff · Stage/Revert/行评论）、终端（等宽输出 / 会话流 / 复制粘贴清屏 / scrollback）——均**标后续**，不设计、不实现，但**不静默丢弃**（框架预留其位）。

#### E. 承接对话跳转 & 消费目录树

- **承接「文档地址→文件页签」**：对话里点某文档地址（对话侧只发起，本模块承接）→ 打开 / 聚焦**文件页签**并显示该文件；右栏收起则顺带展开。
- **「改动 / diff → 代码审核」顺延后续**：因代码审核内部本轮不做，v1 的「点对话改动/diff → 代码审核并聚焦该文件」映射**本轮顺延后续**（不静默丢弃；待代码审核内部落地时兑现）。
- **消费目录树「选中文件」**：目录树选中某文件 → 打开 / 聚焦对应文件页签（见 C）；并与目录树**双向联动**（见 C 联动）。

#### F. 面板级聚合态

- **面板级空 / 加载 / 错误 / 能力门（更新主机·不降级）/ 离线** 五态，与各页签内容态**区分**（详见 §3.6 / sRS12）。

#### G. 主题

- 走 **codePilot** 主题（GitHub 浅色默认 + 深色一并适配），与外壳**同一套主题来源**，不自带冲突配色（主题取值 / 切换机制归 codepilot-layout，本需求不定义）。选中 / 激活态 = 很淡的灰高亮（浅底深字，绝非黑底白字）；蓝仅点缀。

#### H. 平台

- **桌面 only**；移动 / 浏览器紧凑态 deferred。

### 深度切分 · 显式论证

> 为什么**框架全做 + 文件 / 浏览器全做**、**对话 / 代码审核 / 终端只声明框架标后续**？从三个角度论证。

**① 用户价值角度**

- **文件（全做·可编辑）**：这是「看清并就地改一个文件」的落点。目录树只做「定位 + 选中」、对话只做「发起跳转」——两者的**下文都在这里**，且是**双向**的（切文件页签要反向定位树）。缺文件页签全态，用户点了树 / 点了对话里的文档都**没有反应**，切页签时也**丢失「我在哪」**。可编辑是董事长明令（否决 v1 只读）——用户在审改流里就地改一两处的诉求真实且高频。
- **浏览器（全做·Codex 对齐）**：核心价值是**「把看到的问题精确指给 agent」**（截图→标注→进 composer），这是一条自足闭环。缺标注入对话，浏览器只是孤立预览窗、脱离主循环。全量对齐成熟范式，一次做透不留半成品。
- **对话 / 代码审核 / 终端（声明框架·后续）**：它们的**可见价值**（侧边聊、审 diff、看输出）确有需求，但其**内部是可分离的重基建**——侧边对话要接整套会话模型、代码审核要接 diff 引擎 + Stage/Revert 写语义、终端要接会话流 + scrollback。本轮先立框架、标后续，不在没摸清真实用法前一次铺开。

**② 分阶段避免返工角度**

- 文件页签的**契约稳定**（读一个文件渲染 / 编辑 / 保存 / 冲突）、浏览器的**闭环稳定**（导航 + 截图标注 + 进 composer），做全**不会返工**。
- 对话 / 代码审核 / 终端的**内部模型若现在就定死**，很可能在摸清真实用法前**建错、返工**；而**五类框架 + 实例规则是稳定外壳**——现在立框架、以后补三类内部，**不推翻框架**。这正是 codepilot-layout「先立形、再填细节」的分阶段铁律。

**③ 与兄弟模块边界角度**

- **文件页签必须做全**，否则 **file-tree 的承诺落空**：file-tree §2「不做」明写「文件内容富预览属右侧边栏文件页签」——这笔账记在本页签，本轮兑现（且升级为可编辑），双向边界才闭合。
- **浏览器加入对话**只负责「发起添加」，**composer 渲染归 conversation-page**；**代码审核内部后续**，不侵占兄弟模块，也不制造跨模块的半成品。
- **文件页签命令目录树 reveal / 重根**只是**消费 + 命令** file-tree 公共能力（file-tree §2⑧：接受外部目录输入），**不重画树**，边界不越界。

### 不做（逐条写死 · 防范围蔓延 · 每条后续项不得静默丢弃）

- **不重定义壳行为**：右栏 toggle（顶栏、默认收起）、宽度（默认 480 / min 320 / max 800）、相邻手柄拖拽改宽、按工作区记忆宽度、需 active workspace 才可用、「展开右侧边栏」公共壳行为——**全部沿用壳子 `2026-06-28-shell` 与 `2026-06-27-codepilot-layout`，本需求一概不改、不重写**。
- **不做目录树**：定位 / 选中 / 搜索 / 切目录 / 文件图标 / 树内右键 / 内联新建重命名删除 / 拖拽——**属 file-tree 模块**（独立第 4 区）；**文件页签只消费其「选中文件」并命令其 reveal / 重根，不重画树**。
- **不做对话页签内部**（**后续**）：右栏侧边会话 / 子对话。
- **不做代码审核页签内部**（**后续**）：工作区 diff / Stage / Revert / 行评论 / 对话「改动·diff→代码审核」映射。
- **不做终端页签内部**（**后续**）：等宽输出 / 会话流 / 复制粘贴清屏 / 多会话 / 尺寸重排 / scrollback / 活动指示。
- **不做对话侧「发起跳转」的交互**（属 `2026-06-28-conversation-page`）：在对话里哪里点、怎么触发由对话页负责；本需求**只承接「文档地址→文件页签」被跳转打开这一态**。
- **不做 composer 对附件的渲染**（属 `2026-06-28-conversation-page`）：本需求只负责把「标注截图 + 元素上下文」**送入 composer 这一步**。
- **不定义主题取值 / 切换机制 / 入口**（归 codepilot-layout）。
- **不做浏览器深层内部**（**后续**，Codex 本身亦未全给）：浏览器内多可见标签页 / 完整 devtools 面板 / 书签 / 历史。
- **不做移动 / 浏览器紧凑态**（**deferred**）。
- **不涉及协议 / RPC / 能力标志**：纯前端设计需求；能力门是架构师 P2 的事，本 WHAT 层只说「依赖某能力」不点名。

## 3. 流程（端到端）

> 每态有入口、有出口，无死胡同。覆盖框架 / 文件全流程（含编辑保存冲突）/ 浏览器全流程（含标注加对话）/ 放大 / 对话承接 / 树双向联动 / 面板级聚合。

### 3.1 页签框架

- **展开右侧侧边栏 → 落启动器默认态**：用户点顶栏右栏 toggle 展开右侧侧边栏（壳行为）→ 若**无任何已打开页签**，落**启动器列表**（五类竖排：文件 / 浏览器可用；对话 / 代码审核 / 终端禁用+「后续」，各带快捷键提示）；顶部仅 ⤢ + 收起，无 tab 条、无「新选项卡 +」。出口 = 点任一可用项开页签 / ⤢ 放大 / 收起交还壳。
- **从启动器开页签**：点可用项（文件 / 浏览器）或按其快捷键 → 打开对应类型页签、tab 条出现（含「新选项卡 +」）。点禁用项（对话 / 代码审核 / 终端）→ 无反应（保持禁用态，标「后续」）。出口 = 切页签 / 新建 / 关闭 / 调序 / 放大。
- **新选项卡 +**：点 tab 条「新选项卡 +」→ 弹下拉【文件 / 浏览器可用；对话 / 代码审核 / 终端禁用+后续】→ 选可用项即追加对应页签并聚焦它；快捷键等价触发；**代码审核受单实例约束**——已存在时选它 = 聚焦既有（本轮禁用，规则仅框架声明）。点下拉外 / Esc → 关下拉、不新增。
- **切页签**：点某页签 → 切到其内容；当前页签呈**胶囊高亮**。**切到文件页签时触发页签↔树联动**（见 3.2.联动）。
- **悬浮关闭 ✕**：页签悬浮 → 行尾浮出 ✕ → 点它关该页签（所有页签可关，关 = 仅布局、可重开）。**分叉 · 关有脏改动的文件页签** → 先弹关闭未保存确认（见 3.2）。
- **拖拽调序**：拖某页签左右移动 → 显放置指示线 → 松开即在指示位落位；无固定首位约束。
- **页签右键（3 项）**：右键某页签 → **关闭页签**（关该页签）/ **关闭其它**（关除它外全部）/ **关闭全部**（关掉全部）。点项即执行并关菜单；关含脏改动的文件页签时对每个脏页签逐一走关闭未保存确认；点菜单外 / Esc → 关菜单不执行。
- **关掉全部页签 → 回启动器**：当**所有页签都被关闭**时 → 回启动器默认态（sRS1）。新框架无常驻页签，**此出口完整可达**。

### 3.2 文件页签（可编辑）

- **打开文件 · 消费目录树选中**：目录树选中某文件（file-tree 输出「选中文件」）→ **若右栏收起则先展开右栏**（壳行为）→ 打开文件页签显示该文件内容（代码/文本编辑 / md 预览或编辑 / 图片查看 / 只读兜底之一）。**同一文件已开则聚焦既有页签、不新开**。
- **打开文件 · 承接对话文档地址**：对话里点某文档地址（对话页发起跳转）→ 同上打开 / 聚焦文件页签显示该文件；右栏收起则顺带展开。
- **从启动器 / 新选项卡开文件而无选中**：显**空态「选择一个文件」**占位。出口 = 去目录树选一个 / 对话点一个 → 回填内容。
- **查看**：代码/文本 → 语法高亮内容；md → 默认按其形态（编辑或预览，见下）；图片 → 图片查看；未识别/二进制 → 只读兜底（说明无法编辑）。
- **编辑（代码 / 文本 / md 编辑形态）**：在内容区修改 → 进入**编辑中**；一旦有未保存改动 → 页签/标题显**脏标记**。
- **Markdown 编辑 ⇄ 预览**：md 页签内有「编辑 ⇄ 预览」切换 → 编辑形态可改内容、预览形态渲染阅读；两形态间切换不丢未保存改动。
- **保存**：触发保存动作 → **保存中** → **成功**（脏标记消除）/ **失败**（提示 + 可重试，脏标记保留）。
- **还原此文件（经代码/文本编辑区右键）**：放弃未保存改动、回到已存盘版本，脏标记清除；**非脏（无未保存改动）时该项置灰**、不可点。（与右键「保存」成对：保存·无改动置灰 / 还原·非脏置灰。）
- **关闭未保存确认（分叉）**：关闭有脏改动的文件页签 → 弹确认三择一：**保存并关闭**（先保存再关，保存失败则留在页签并提示）/ **放弃更改并关闭**（丢弃未保存改动直接关）/ **取消**（不关闭，回到编辑态）。
- **外部文件变更冲突（分叉）**：页签打开期间该文件被主机侧外部改动 → 弹冲突提示：**重载**（放弃本地未保存改动、载入主机最新）/ **保留本地**（忽略外部变更、以本地为准，后续保存以本地覆盖）/ **对比**（并排看本地与主机最新，看完仍回到三择一）。每个出口都回到可编辑或已重载的确定态。
- **只读兜底（分叉）**：图片 / 二进制 / 未识别 → 只读呈现，无编辑 / 保存 / 脏态；说明该类型无法编辑。
- **换选中 → 聚焦或新开**：目录树换选中另一文件 → 若该文件已开则聚焦其页签、否则新开一个文件页签（同一文件去重）。
- **切树根不删页签（分叉）**：目录树切换树根（换目录）→ **已打开的文件页签全部保留**、内容不变；仅目录树的展示根变了。
- **联动 · 页签 ↔ 树（钉死语义）**：**切到 / 聚焦某文件页签**时，本模块**命令目录树定位到该文件**，按该文件与当前树根的关系分三种确定行为——
  1. **该文件属于当前树根范围、且其所在目录不等于当前树根**（是树根的更深层后代）→ 目录树**保持当前树根不变**，在当前树内把该文件 **reveal** 出来：逐层展开其所有祖先目录 + 滚动使其可见 + 选中该文件行。
  2. **该文件所在目录恰为当前树根**（文件是树根的直接子项、已在首层可见）→ 目录树**不改树根、不改展开结构**（无祖先可展开），仅**选中**该文件行——此即「树根不动」。
  3. **该文件不属于当前树根范围**（不是当前树根的后代）→ 目录树借「file-tree 公共能力（接受外部目录输入）」**以该文件所在目录为新树根重展示**，并选中该文件行。
  - **反向联动**：目录树选中文件 → 打开 / 聚焦对应文件页签（见「打开文件·消费目录树选中」）。
  - **边界**：以上「reveal / 重根 / 选中」的呈现由 **file-tree 负责**，本模块只**发起命令**，**不重画树**。
- **分叉 · 加载**：读取文件中 → 加载指示。**分叉 · 错误**：无法读取该文件（无权限 / 已删除等）→ 提示 + **重试**。**分叉 · 离线**：主机断连 → 见 3.6 / sRS12。
- **右键**：见 §4 sRS4 / sRS5 / sRS7（三套按内容区）。**边界**：文件页签**不含目录树、不做目录树写操作**（归 file-tree）。

### 3.3 浏览器页签（Codex 对齐）

- **打开浏览器**：从启动器 / 新选项卡开浏览器 / 快捷键 → 默认落**「新标签（开始浏览）」空态**（地址栏 + 空提示）。
- **导航 · 前往**：输入 URL → 点「前往」/ 回车 → 内嵌渲染该页；加载中显**加载指示**。**← / → / ⟳**：后退 / 前进 / 刷新（无历史方向的按钮禁用）。
- **设备工具条**：点 URL 栏右侧 **⋯（更多）→ 设备工具条** → 切换设备 / 响应式视口尺寸预览不同屏宽；再点关闭工具条回常规视口。
- **共享渲染**：页签内渲染的页面**用户与 agent 共享同一个**（同一页面双方可见）。
- **隔离沙箱（说明态）**：浏览器**不带**常规配置 / cookie / 扩展 / 登录会话 / 已有标签页；遇登录类页面**不可用** → 显**隔离说明**（非报错，说明沙箱隔离、登录类页面在此不可用）。出口 = 导航到无需登录的页面 / 在外部浏览器打开。
- **进入标注模式**：点右上角**标注按钮**或按快捷键 → 进标注模式，页面上出现**选择叠层**：**点选某元素**（选中一个 UI 组件、高亮其边界）或 **Shift + 拖拽选一块区域**。
- **写批注 + 粒度样式反馈**：选定后出现**批注输入框** → 输入批注文字；点输入框旁**配置图标** → 给字体 / 文字 / 间距 / 颜色等更细的样式反馈，**发送前在页面上直接预览**该样式效果。
- **加入对话（联动）**：把「批注截图 + 元素上下文（+ 可选粒度样式反馈）」**加入对话 composer** → 出现在对话线程输入框（**composer 渲染归 conversation-page**）→ 交给 agent。**分叉 · 无活跃对话** → 「加入对话」动作**禁用**（无可加入的 composer，呼应 file-tree「将文件添加到聊天·无活跃对话禁用」）。出口 = 有活跃对话时可加入 / 退出标注模式。
- **退出标注模式**：再点标注按钮 / Esc → 回常规浏览态。
- **右键（6 项）**：后退 / 前进 / 刷新 / 复制链接 / 进入标注模式 / 在外部浏览器打开。
- **分叉 · 空**：未导航 → 「开始浏览」占位。**分叉 · 错误**：页面加载失败 → 占位 + **重试**。**分叉 · 离线**：主机断连 → 见 3.6 / sRS12。
- **边界**：浏览器内多可见标签页 / 完整 devtools / 书签 / 历史**后续**。

### 3.4 放大缩小

- **整面板放大 / 还原**：停靠态点 tab 条 ⤢ → 右侧侧边栏**扩展占满对话区的空间**（左栏保留、目录树按其自身显隐保留）；图标变 ⤡ → 点 ⤡ 还原回停靠列（恢复对话区）。旁边的**收起**仍可把整列收起、右栏 toggle 交还壳。
- **单页签放大 / 还原**：点某页签内容右上角 ⤢ → 单独放大该页签内容（文件 / 浏览器皆可）；再 ⤡ 还原。放大态下内容**照常实时刷新**（浏览器页面照常加载、文件编辑照常生效）。

### 3.5 对话承接

- **文档地址 → 文件页签**：对话页发起跳转（本需求不画对话侧）→ 右侧侧边栏**承接**：打开 / 聚焦**文件页签**并显示该文件；若右栏收起则跳转**顺带展开**右栏（沿用壳「展开右侧边栏」公共壳行为）。
- **改动 / diff → 代码审核（顺延后续）**：因代码审核内部本轮不做，对话点「改动 / diff」跳到代码审核的映射**本轮顺延后续**（不静默丢弃，待代码审核落地兑现）。

### 3.6 面板级聚合态

- **面板级离线（聚合）**：主机断连 → **整面板所有页签**统一冻结当前内容 + 顶部一条重连提示；主机恢复后各页签按各自能力恢复。出口 = 重连。
- **面板级加载（聚合）**：面板打开 / 页签恢复 / 首次建立工作面板中 → 面板级加载指示；完成落内容，失败转面板级错误。
- **面板级错误（聚合）**：无法建立工作面板（罕见的面板级失败）→ 提示 + **重试**。
- **面板级能力门（聚合 · 更新主机·不降级）**：主机版本过低 / 缺工作面板能力 → 显「更新主机以使用工作面板」+「查看如何更新」引导升级；**不提供降级 / 模拟路径**。出口 = 升级主机后能力就绪即可用。
- **面板级空（聚合）** = **启动器默认态**（无任何已打开页签）= sRS1；出口 = 点启动器可用项开页签。
- **与各页签内容态区分**：面板级空（无页签）≠ 文件空（未选文件）≠ 浏览器空（未导航）；某页签空但另一页签正常时，面板正常、仅该页签显空。

**全态交互聚焦**：每屏覆盖 默认 / hover / 活跃（胶囊高亮）/ 运行 / 禁用 / 空 / 加载 / 错误 / 冲突（文件）/ 离线 / 浅深主题，以及各屏右键菜单（sRS3 页签右键 3 项 / sRS4 代码文本 7 项 / sRS5 md 预览 5 项 + 图片 4 项 / sRS8·9·10 浏览器 6 项 / sRS1·6·7·11·12 无独立右键或随内容区）与每个可点元素的点击效果。

## 5. 边界与依赖

### 与既有设计的关系（分工边界）

- **建立在壳子之上（壳行为一概不重定义）**：本需求填的是壳子 `2026-06-28-shell` §7.d 第 22–25 条标注的右侧侧边栏空容器。右栏 toggle（顶栏 · 默认收起）、宽度（默认 480 / min 320 / max 800）、相邻手柄拖拽改宽、按工作区记忆宽度、需 active workspace、**「展开右侧边栏」公共壳行为**——**全部是壳行为**（壳子 + `2026-06-27-codepilot-layout`），**本需求沿用不改**。本需求只关心「容器里装什么、怎么用」。
- **与目录树（file-tree 模块）边界**：目录树只做「定位 + 选中 + 搜索 + 切目录 + 图标 + 树内右键 + 内联新建重命名删除」，是**独立的第 4 区**；**文件内容富预览与编辑属本需求的文件页签**。文件页签**不重画树**——它**消费** file-tree 输出的「选中文件」，并**命令** file-tree 公共能力执行 **reveal / 重根 / 选中**（file-tree §2⑧：目录树能力对外开放为公共能力、接受「外部指定的目录」作为输入）。文件的写操作（新建/重命名/删除/剪切复制粘贴）归 file-tree，不在本页签。
- **与对话页（conversation-page）联动**：对话页点击文档地址会**发起跳转到右栏**——**对话页只负责「发起跳转这一步」**（conversation-page §2「点击代码 / 文件 / 改动等跳到右栏的目标内容不在本需求，只负责发起跳转」）；**右侧侧边栏负责「被跳转后打开/聚焦文件页签并显示该文件」这一态**。反向，浏览器「标注截图加入对话」只负责**发起添加**（送入 composer）；**composer 如何渲染该附件归 conversation-page**。本需求**不画对话侧交互、不画 composer 渲染**。（「改动/diff→代码审核」映射因代码审核内部本轮不做而顺延后续。）
- **与 codepilot-layout（主题）**：走 **codePilot** 主题（GitHub 浅色默认 + 深色），与外壳同一套主题来源；**主题取值 / 浅深切换机制 / 入口归 codepilot-layout**，本需求不定义、不自带冲突配色。

### 平台与能力门（用 WHAT 描述 · 不点名 RPC / 接口）

- **桌面 only**；移动 / 浏览器紧凑态 deferred。
- **能力门 · 读取文件内容**：依赖「主机能读出某文件内容供查看」的能力。不可用 → 文件页签走加载 / 错误 / 离线态。
- **能力门 · 写入文件内容**：依赖「主机能把编辑后的文件内容写回」的能力。不可用 → 保存走失败态（可重试）；写能力整体缺失 → 文件页签退化为只读并说明。
- **能力门 · 外部变更感知**：依赖「主机能感知某文件在打开期间被外部改动」的能力。不可用 → 不弹冲突提示（不影响查看/编辑/保存主路径）。
- **能力门 · 目录树定位联动**：依赖 file-tree 公共能力「接受外部目录输入 / 定位到指定文件（reveal 或重根）」。不可用 → 文件页签仍可查看/编辑，仅树联动不生效。
- **能力门 · 内嵌网页渲染**：依赖「客户端能在页签内内嵌渲染一个网页」的能力。不可用 → 浏览器页签走错误 / 离线态。
- **能力门 · 网页截图与元素上下文**：依赖「客户端能对内嵌页面截图并取到所选元素的上下文」的能力。不可用 → 标注模式走错误/不可用说明。
- **能力门 · 加入对话 composer**：依赖「客户端能把一条引用/附件送入当前活跃对话的 composer」的能力（同 file-tree「将文件添加到聊天」同款门）。无活跃对话 → 「加入对话」禁用。
- 以上均为**能力门**：能力在则功能可用，能力缺则相应路径给出可恢复的提示态，**不写降级版另一套实现**。能力门的具体形态（协议 / RPC / 能力标志）属架构师 P2，本需求不点名。
- **无老用户 / 迁移**（fork 未上线）：不写存量兼容。

## 6. 验收标准（逐条可判定 · 能 / 否）

**页签框架 · 启动器 · 呈现项**

1. 右侧侧边栏展开且**无任何已打开页签**时，**能**落**启动器列表**（竖排五类），且顶部**仅有 ⤢ 放大 + 收起**、**无 tab 条、无「新选项卡 +」**。
2. 启动器**恰呈现五类**（对话 / 浏览器 / 代码审核 / 终端 / 文件），其中**文件、浏览器为可用项**，**对话 / 代码审核 / 终端三行为禁用 + 「后续」标**、不可点。
3. 点启动器**文件 / 浏览器**（或按其快捷键）**能**打开对应类型页签，此后 tab 条**能**出现（含「新选项卡 +」）；点三个禁用项**无**打开效果。

**页签框架 · 五类体系 + 实例规则**

4. 文档**明确声明五类页签**（对话 / 浏览器 / 代码审核 / 终端 / 文件）及其实例规则：**代码审核 = 单实例**（再次打开=聚焦既有），**对话 / 浏览器 / 终端 / 文件 = 多实例**。
5. **文件页签按「同一文件只开一个」去重**（重复打开同一文件=聚焦既有页签、不新开）；**浏览器 / 对话 / 终端各实例相互独立、不去重**（可对同一 URL 开多个浏览器页签）。
6. 同类多个页签**能**用各自标识区分：文件=文件名、浏览器=页面标题（无标题用 URL）；标识过长**能**截断省略。
7. v1「审查固定第一 / ✕ 置灰不可关」框架**已作废**：新框架下**无固定首位、无不可关页签**——**所有已打开页签均可关**。

**页签框架 · Codex tab 头观感**

8. tab 头**能**呈现 Codex 观感：**图标 + 文字页签**、**活跃页签 = 胶囊式高亮**（**非**蓝下划线）、**页签间有细分隔**、**tab 条末尾有「新选项卡 +」**、**右上有 ⤢ 放大 + 收起**。

**页签框架 · 管理交互**

9. 「新选项卡 +」点开的下拉**恰为五类**（文件 / 浏览器可用；对话 / 代码审核 / 终端禁用+后续），各带快捷键提示；选可用项**能**追加对应页签；快捷键**能**等价触发。
10. 页签**悬浮时能**浮出 ✕ 关闭该页签（关 = 仅布局、可重开）；关**有脏改动的文件页签**前**能**弹关闭未保存确认。
11. 页签**能**左右拖拽调序，拖动时**有**放置指示线；**无**固定首位约束。
12. 页签右键**能**弹出菜单，且**恰为 3 项**：关闭页签 / 关闭其它页签 / 关闭全部页签，各项点击效果如 §3.1。
13. **所有页签关闭后能**回到启动器默认态（sRS1）——新框架下此出口**完整可达**（无常驻页签阻挡）。

**放大缩小**

14. tab 条 ⤢ **能**把整面板**放大占满对话区**（左栏保留、目录树按其显隐保留），⤡ **能**还原回停靠列；其旁「收起」仍**能**把整列收起、交还壳。
15. 每个页签内容右上角 ⤢ **能**单独放大该页签内容（文件 / 浏览器皆可），⤡ **能**还原；放大态下内容**能**照常实时刷新。

**文件页签 · 类 VSCode 可编辑（本轮核心）**

16. 文件页签**能**按类型呈现：代码/文本=查看+语法高亮+**编辑**；Markdown=**编辑/预览双态**可切换；图片=**查看（不可编辑）**；未识别/二进制=**只读兜底**（说明无法编辑）。
17. 文件页签**能**消费目录树输出的「选中文件」并显示；**能**承接对话「文档地址」跳转打开并显示该文件；**从启动器/新选项卡开文件而无选中时能**显「选择一个文件」空态。
18. **同一文件重复打开=聚焦既有页签**、不新开；不同文件各一个页签、可多开。
19. 目录树**切换树根（换目录）不删除**已打开的文件页签。
20. 文件被改动未保存时**能**显**脏标记**；**能**保存并给保存中/成功/失败反馈、失败可重试。
21. 关闭有脏改动的文件页签前**能**弹确认，**恰三择一**：保存并关闭 / 放弃更改并关闭 / 取消（不关闭）。
22. 文件在打开期间被外部改动时**能**弹冲突提示，给出口：重载 / 保留本地 / 对比，每个出口都回到确定态。
23. 文件页签**能**覆盖全态：默认 / 编辑中 / 脏 / 保存中·成功·失败 / 空 / 加载 / 错误（+重试）/ 冲突 / 只读兜底 / 离线，每个非常规态**有**定义出口。

**文件页签 · 页签 ↔ 树 reveal 语义（钉死·可判定）**

24. 切到/聚焦某文件页签时，目录树**能**按三分支确定行为定位该文件：① 文件是当前树根的**更深层后代** → 当前树内 reveal（展开祖先+滚动+选中），**不改树根**；② 文件所在目录**恰为当前树根**（直接子项）→ **树根不动、不改展开结构**，仅选中该文件行；③ 文件**不属于当前树根范围** → 以其所在目录为**新树根重展示**+选中。
25. 反向：目录树选中文件**能**打开/聚焦对应文件页签；文档**明确**此联动是**命令 file-tree 公共能力执行定位**，本模块**不重画树**。

**文件页签 · 右键（三套·可判定）**

26. 文件页签**能**按内容区弹三套右键，项数严格：**代码/文本编辑区 9 项**（剪切/复制/粘贴/全选/保存/还原此文件/复制文件路径/在目录树中定位/在 Finder 中显示）；**Markdown 预览区 5 项**（复制选中/复制文件路径/在目录树中定位/在 Finder 中显示/切到编辑）；**图片查看区 4 项**（复制图片/复制文件路径/在目录树中定位/在 Finder 中显示）；**目录树写操作（新建/重命名/删除等）不在本页签任何右键里**。

**浏览器页签 · Codex 全量对齐（本轮核心）**

27. 浏览器页签**能**显地址栏（← → ⟳ + URL + 前往）+ 内嵌页面预览；未导航时**能**显「开始浏览」空态；**能**经 URL 栏右侧 **⋯ → 设备工具条**切换设备/视口尺寸。
28. 浏览器**能**呈现隔离沙箱说明态：不使用常规配置/cookie/扩展/登录会话/已有标签页，登录类页面不可用（作为说明、非报错）；用户与 agent **共享同一渲染页面**。
29. 浏览器**能**进入标注模式（右上角按钮或快捷键），**能点选某元素**或 **Shift+拖拽选一块区域**，捕获**批注文字 + 截图 + 元素上下文**；**能**经批注框旁配置图标给字体/文字/间距/颜色等粒度样式反馈并**发送前在页面上直接预览**。
30. 浏览器**能**把「批注截图 + 元素上下文」**加入对话 composer**（发起添加）；**无活跃对话时该动作禁用**；文档**明确** composer 对该附件的渲染归 conversation-page、本模块只负责发起添加这一步。
31. 浏览器右键**恰为 6 项**（后退 / 前进 / 刷新 / 复制链接 / 进入标注模式 / 在外部浏览器打开）；**能**覆盖：默认 / 加载 / 空 / 标注模式 / 错误（+重试）/ 隔离说明 / 离线。

**对话承接 & 目录树消费**

32. 对话点某**文档地址**跳转时，右侧侧边栏**能**打开/聚焦**文件页签**并显示该文件；右侧侧边栏若收起，跳转**能**顺带展开它（沿用壳「展开右侧边栏」壳行为，不新增布局原语）。
33. 文档**明确**：对话侧「发起跳转」的交互归 conversation-page，本需求**只承接**；「改动/diff→代码审核」映射因代码审核本轮不做而**顺延后续**（不静默丢弃）。

**面板级聚合态**

34. 主机**离线**时**整面板所有页签统一冻结** + 顶部一条重连提示，主机恢复后各页签按各自能力恢复；面板级**空/加载/错误**分别对应启动器默认态/面板恢复中/无法建立工作面板（+重试）；主机**版本过低/缺工作面板能力**时**能**显「更新主机以使用工作面板」+查看如何更新、**不提供降级路径**；以上面板级态相互**并列且与各页签内容态可区分**。

**主题**

35. 右侧侧边栏**能**走 codePilot 主题（GitHub 浅色默认 + 深色一并适配），读**同一套主题来源**、不自带冲突配色；活跃/选中态为很淡的灰高亮（浅底深字、绝非黑底白字）；主题取值/切换机制**不在本需求定义**（归 codepilot-layout）。

**边界（不做，逐条声明不静默丢弃）**

## 7. 发散思考建议项（单列 · 每条「建议项 · 待董事长闸 1 采纳」+ 论证 · 与必做范围明确隔离）

> 以下**均为建议项、不在 §2/§4/§6 的必做范围内**，探索 VSCode / Cursor / Codex 等工作面板的真实使用痛点，供董事长在闸 1 决定是否纳入。**未获采纳前不进入必做范围**；采纳的才增补进相应屏与验收。

1. **建议项 · 待董事长闸 1 采纳 — 文件内查找 / 替换**（观感参照 VSCode ⌘F / ⌘⌥F）。**痛点**：编辑长文件时，定位一处文本或批量替换是刚需；没有文件内查找，用户只能靠眼扫或滚动，改多处极慢。**价值**：把「找到 + 改到」收在文件页签内，配合可编辑形态形成闭环。**隔离**：仅文件页签内、不影响目录树全局搜索（那归 file-tree）。
2. **建议项 · 待董事长闸 1 采纳 — 跳转到行**（点行号 / 快捷键跳到第 N 行）。**痛点**：对话 / 代码审核常引用「第 N 行」，用户手动滚动找行既慢又易错。**价值**：与「文档地址可带行锚点」协同——对话点带行号的文档地址可直达该行，把「打开文件」升级为「打开并定位到那一行」。**隔离**：仅文件页签内定位，不改对话侧发起交互。
3. **建议项 · 待董事长闸 1 采纳 — 页签溢出下拉**。**痛点**：页签开多了会超出 tab 条宽度，被挤出可视区的页签**无法触达**（可达性黑洞）。**价值**：tab 条末尾加一个「溢出下拉」列出被隐藏页签，一点即达，保证任意多页签都可切换。**隔离**：纯框架层交互，不涉及任何页签内部。
4. **建议项 · 待董事长闸 1 采纳 — 最近关闭重开**（观感参照 ⌘⇧T）。**痛点**：误关页签（尤其正在看/改的文件）是高频事故，重新从目录树/对话找回很烦。**价值**：一键重开最近关闭的页签，是廉价、高频受益的兜底；文件页签重开还能恢复到关闭前的滚动/编辑现场。**隔离**：框架层，不新增页签类型。
5. **建议项 · 待董事长闸 1 采纳 — 键盘循环切换页签**（观感参照 ⌃Tab / ⌘⇧[ ]）。**痛点**：页签多时用鼠标逐个点切换慢；键盘流用户想不摸鼠标切页签。**价值**：键盘正/反向循环切换 + 触发树联动，提升重度多页签用户的流畅度。**隔离**：纯键位，落值与全局键位裁决可归快捷键设置模块。
6. **建议项 · 待董事长闸 1 采纳 — 会话级持久化已开页签**。**痛点**：重开面板 / 刷新客户端后，之前开的一组文件/浏览器页签全没了，用户要重建整个工作区现场。**价值**：按工作区记住「上次开了哪些页签、哪个活跃」，重开即恢复现场，与壳「按工作区记忆宽度」一脉相承。**隔离**：状态记忆策略较重，故列建议而非必做；采纳后需定义「记住什么、恢复到何种程度（是否恢复未保存草稿）」。
7. **建议项 · 待董事长闸 1 采纳 — 右侧代码小地图 minimap**（观感参照 VSCode）。**痛点**：长文件里滚动定位缺乏全貌感，用户不知道「自己在文件哪一段、改动/命中散在何处」。**价值**：文件页签右侧一条缩略全貌，改动行 / 查找命中在小地图上标记，点即快速跳转。**隔离**：仅文件页签内视觉附件，与必做的高亮/编辑分离，虚线隔离不混入本轮。
8. **建议项 · 待董事长闸 1 采纳 — 浏览器控制台 / 网络速览**（轻量 · **≠ 完整 devtools**）。**痛点**：agent 建的预览页报错时，用户看不到控制台/网络错误，只能凭肉眼猜。**价值**：浏览器页签内嵌一个轻量诊断（错误计数徽标 + 点开速览近期错误/请求），把「页面为什么坏」直接暴露给用户与 agent；**明确区别于完整 devtools**（后者列入浏览器深层内部·后续）。**隔离**：仅浏览器页签内，不做完整 devtools 面板。
9. **建议项 · 待董事长闸 1 采纳 — 一键复制元素上下文**（与标注 sRS9 配合）。**痛点**：标注选中某元素后，用户想把该元素的定位信息（元素选择器 / 尺寸等）单独抓给 agent，目前只能连截图一起走。**价值**：标注模式选中元素后一键复制其元素上下文（元素选择器 / 尺寸等），随批注给 agent，定位更精确。**隔离**：仅浏览器标注内的复制动作，不改「加入对话」主链路。
