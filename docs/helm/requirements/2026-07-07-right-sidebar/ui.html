面板级（非某个页签）的非常规态，替换整个内容区。每态标出出口，无死胡同：空（无已开页签 → 启动器引导）/ 加载（首连拉能力）/ 错误（能力/读取失败）/ 能力门（主机版本过低缺工作面板能力 → 更新主机）/ 离线（主机断连）。参照 file-tree sFT6 手法。

布局 + 状态（聚合 · 每态标出口）
布局
桌面 only：面板级非常规态占满右面板内容区（替换 tab 内容）。紧凑 / 手机：deferred。
空
无已开页签 → 启动器引导；出口：点项开 tab（= sRS1）。
加载
首连主机拉能力 → tab 条 + 内容骨架，通常瞬时；出口：加载完 → 默认 / 上次页签。
错误
能力 / 读取失败 → 红「无法加载工作面板」+ 重试；出口：重试成功 → 恢复。
能力门
主机版本过低缺能力 → 「更新主机以使用工作面板」；出口：升级主机后可用；无降级。
离线
主机断连 → 灰「主机离线」+ 重连、页签保留冻结；出口：主机恢复 → 自动重连。
hover / active / 运行 / 禁用
状态卡的按钮 hover 变深；无常驻选中；无运行 / 禁用态（面板级引导，不承载运行内容）。
深色
状态卡图标底 #21262d、错误红 #f85149、离线暖灰、能力门蓝 #1f6feb（见深色卡）。
右键菜单
无独立右键。面板级状态卡仅提供重试 / 重连 / 查看更新 / 启动器项等单击按钮，不设右键菜单。页签与内容级右键在恢复正常态后由各页签提供（见 sRS2–sRS5）。
