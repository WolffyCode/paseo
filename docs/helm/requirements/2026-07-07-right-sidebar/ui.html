交互注解
面板级 vs 各页签内容态（务必区分 · 每态出口）
  1. 1
    面板空 = 无任何已开页签 = 启动器（sRS1）。≠ 文件空「选择一个文件」/ 浏览器空「开始浏览」（那是某页签内的空）。出口：点可用项开页签。
  2. 2
    面板加载 = 首次建立/恢复工作面板中（整面板级 spinner）。≠ 某文件「读取中」/ 浏览器「导航中」。出口：完成落内容 / 失败转面板错误。
  3. 3
    面板错误 = 无法建立工作面板通道 + 重试。≠ 某文件「无法读取」/ 浏览器「加载失败」。出口：重试 / 收起稍后再开。
  4. 4
    能力门：主机版本过低/缺能力 →「更新主机以使用工作面板」+「查看如何更新」；不提供降级/模拟路径（不写降级版另一套）。出口：升级主机 → 能力就绪即用。
  5. 5
    面板离线：主机断连 → 整面板所有页签统一冻结当前内容 + 顶部一条重连提示；主机恢复后各页签按各自能力恢复。出口：重连（自动 + 可手动）。举例：审查空「没有改动」≠ 面板空「无页签」；某页签在跑而另一页签空 → 面板正常、仅该页签显空。
