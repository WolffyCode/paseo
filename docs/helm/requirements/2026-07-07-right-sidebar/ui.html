联动语义（方向画清 · 本模块承接 / 命令，不重画树）
  1. 1
    树 → 页签（承接）：目录树选中某文件（file-tree 输出「选中」）→ 本模块打开或聚焦该文件页签；若右栏当前收起，跳转顺带展开右栏（沿用壳「展开右侧边栏」公共行为，不新增布局原语）。
  2. 2
    页签 → 树（命令）：切到某文件页签 / 打开新文件页签 → 命令 file-tree reveal，按文件与当前树根的关系分三支：① 文件是当前树根更深层后代 → 当前树内 reveal（展开祖先 + 滚动 + 选中），不改树根；② 文件所在目录恰为当前树根（直接子项）→ 树根 / 展开结构不动，仍选中该文件行；③ 文件不属于当前树根范围 → 命令 file-tree 以该文件所在目录为新树根重展示 + 选中该行。
  3. 3
    对话地址 → 页签（承接）：对话消息里的文档地址被点（对话侧发起）→ 本模块打开对应文件页签并预览/编辑。对话侧交互归 conversation-page，本模块只承接「被打开」这一态。
  4. 4
    去重：再次打开已在页签里的同一文件 → 聚焦既有页签（活跃胶囊移过去），不新增重复页签。
  5. 5
    切树根不删页签：目录树切换工作区根（第 4 区行为）不影响已打开的文件页签——页签原样保留；仅后续「页签 → 树 reveal」在新根下按新树定位。

交互注解
面板级 vs 各页签内容态（务必区分 · 每态出口）
  1. 1
    面板空 = 无任何已开页签 = 启动器（sRS1）。≠ 文件空「选择一个文件」（那是某文件页签内的空，见 sRS7；浏览器空等其它页签内空随其模块后续）。出口：点文件开页签。
  2. 2
    面板加载 = 首次建立/恢复工作面板中（整面板级 spinner）。≠ 某文件「读取中」。出口：完成落内容 / 失败转面板错误。
  3. 3
    面板错误 = 无法建立工作面板通道 + 重试。≠ 某文件「无法读取」。出口：重试 / 收起稍后再开。
  4. 4
    能力门：主机版本过低/缺能力 →「更新主机以使用工作面板」+「查看如何更新」；不提供降级/模拟路径（不写降级版另一套）。出口：升级主机 → 能力就绪即用。
  5. 5
    面板离线：主机断连 → 整面板所有页签统一冻结当前内容 + 顶部一条重连提示；主机恢复后各页签按各自能力恢复。出口：重连（自动 + 可手动）。举例：某文件页签编辑中而另一文件页签空 → 面板正常、仅该页签显「选择一个文件」；≠ 面板空「无页签」。
