# 需求 · 桌面 Composer 运行配置

> 日期：2026-08-01 · 状态：已实现，待 Gate 3 验收 · 配套 UI：[ui.html](./ui.html)

## 1. 目标

在 PC 客户端与 Web 的对话画布中，把 Composer 调整为圆润、紧凑且高频功能直达的输入表面，把运行配置稳定放在输入框下方的独立单行区域，并让新对话空白画布具有明确而克制的视觉起点。

## 2. 范围

- 本期只覆盖 Electron PC 客户端和桌面 Web。
- 手机端与窄屏设计器不在本期范围，保持现状。
- 覆盖中区新对话、进行中根对话及其它可编辑桌面对话 Composer。
- 新对话空态标题只覆盖 PC/Web 中区主画布，不进入右侧窄对话。

## 3. 输入区

1. 工作目录位于输入框上方且为可选项：已选时显示项目名和缩略路径，未选时显示“对话 · 未选择工作目录”；会话开始后不可切换，但不增加醒目的锁定徽标挤占路径空间。
2. 输入框使用 16px 圆角和稳定宽度；正文高度随输入增长，但不挤动下方运行配置结构。
3. 输入框左下依次保留圆形“+”和独立语音按钮，右下保留圆形发送/停止按钮；空输入时发送按钮不可点击，但圆形底和向上箭头始终可见，不能隐藏图标。
4. “+”只承载附件等低频动作，不收纳提供方、模型、推理强度、运行模式或语音。
5. 删除 `@` 按钮、引导文案和文件提及自动补全；`/` 命令补全继续可用。
6. PC/Web 中区新对话在 Composer 上方的空白消息区中部显示小字号“新对话”标识和“今天想构建点什么？”主标题；不增加模板卡片或额外操作入口。
7. 新对话标题在选择目录、编辑草稿与创建失败时保留，首次发送时让位给乐观消息和真实消息流；进行中对话、右侧窄对话与手机端不显示。

## 4. 运行配置行

1. 输入框下方是一条独立的“运行配置”行，整体与输入框同宽且只占一行。
2. 左侧以小字号图标加“运行配置”标识；竖线从标签后开始分隔左右区域；全部配置控件在右侧靠右排列。
3. 第一选择器完整显示“提供方 · 中转站 · 模型”，宽度随内容增长并设最大宽度，长名称在有限空间内省略而不撑破布局。
4. 第二选择器只显示并选择当前模型支持的英文推理强度。
5. 第三选择器显示本地化后的中文运行模式；风险状态以小圆点表达。
6. 当前上下文放在同一运行配置行，通过“上下文 + 百分比”进入 token 与额度详情；用量尚未返回时显示可点击的 `--` 稳定占位。
7. 当前模型返回的其它 provider feature 紧跟在当前行，能力不存在时不显示空占位。
8. PC/Web 中区被右侧工作区压窄时，运行配置保持单行；每个文字选择器在自身范围内省略长值，但仍保留独立入口和必要文字，不改成图标模式，也不回流到“+”。

## 5. 提供方 → 中转站 → 模型

1. 第一选择器是一个三级结构，不再额外显示作用重复的提供方控件。
2. 新对话尚未发送时可切换提供方；首条消息创建真实对话后，提供方锁定，但中转站和模型仍可查看与改选。
3. 打开选择器时按当前完成度进入正确层级：未选提供方进入提供方；已选提供方但未选中转站进入中转站；已选中转站和模型默认进入模型。
4. 选择提供方后进入该提供方的中转站列表；选择中转站后进入其模型列表；顶部路径允许返回已完成的层级，锁定提供方不可返回修改。
5. 每个提供方都有“官方直连”选项；配置中已启用的中转站按设置顺序展示，仅列出该中转站明确暴露的模型。
6. 所有选择面板都是锚定当前控件正上方的 select 下拉，覆盖输入框上方区域，不占用画布空白另起浮层。
7. Electron 与 Web 点击工作目录都打开紧凑的锚定浮层；浮层只搜索和选择当前电脑已知的已有/推荐项目。
8. 浮层底部显示“浏览文件系统…”并进入 Helm 自己的双栏目录浏览器；本期不显示或切换 Host，不提供远程多设备目录浏览。

## 6. 纯对话与目录归属

1. 工作目录可以不选；只要输入内容和运行配置有效，未选目录也允许发送。
2. 选择目录后沿用现有 workspace 创建链路，真实 Agent 归入对应项目。
3. 未选目录发送时创建 conversation-only Agent：不创建 workspace、不写项目归属，左树按不属于项目的根对话展示。
4. conversation-only Agent 使用 daemon 内部独立运行目录，不得把客户端占位 cwd 或 daemon 启动目录当作用户工作目录。
5. 无 workspace 的纯对话不能打开 workspace 文件、终端、浏览器和 review 工具；Composer 与消息流继续可用。
6. 新客户端只在 `server_info.features.conversationOnlyAgents` 为真时发送纯对话请求；旧 Host 缺少能力时提示更新 Host，不降级创建隐式 workspace。

## 7. 状态与边界

- 加载、空、错误、离线和能力缺失均保留输入内容，并提供重试或设置出口。
- 中转站指 API 供应商，不是连接 Host 的 Relay。
- 中转站配置选择写入 Host 配置并用于 Composer 回显；daemon 启动链路尚未消费该配置，因此本期不宣称切换了活动 Agent 的 API endpoint。
- 推理强度保留英文；运行模式使用中文；上下文信息与运行配置同一行展示。
- 右键菜单：无新增菜单。

## 8. 验收标准

1. 桌面输入区、工作目录和运行配置在 760px 宽度内无换行、重叠或横向滚动。
2. 运行配置标签在竖线左侧，配置控件在竖线右侧靠右；标签字号明显小于输入正文。
3. 第一选择器是唯一的提供方/中转站/模型入口；第二选择器只有推理强度，第三选择器是中文运行模式。
4. 已完成三级选择时打开默认展示模型，缺中转站时展示中转站，缺提供方时展示提供方。
5. 新对话可换提供方，已开始对话不可换提供方。
6. 模型、推理强度和运行模式下拉均锚定在各自触发器正上方。
7. 输入框左下同时可见“+”和语音；空输入时发送按钮保留圆形底和向上箭头但不可点击；`@` 入口及自动补全均不存在，`/` 命令仍有效。
8. 打开右侧工作区压窄中区时，运行配置不裁切、不重叠；三个核心选择器仍分别可点并在正上方打开完整下拉。
9. PC/Web 中区空白新对话显示两行轻量标题，标题不遮挡 Composer；首次发送后标题消失，消息流从原位置接管。
10. 工作目录浮层可搜索并选择当前电脑已知项目；点击“浏览文件系统…”进入左右双栏、分别可滚动的目录浏览器，确认后返回当前电脑 daemon 可解析的绝对路径。
11. 未选工作目录时可以直接发送；创建结果没有 workspace/project 归属，仍留在中区并可继续对话。
12. 无 workspace 对话不会打开文件、终端、浏览器或 review 面板；旧 Host 缺少能力时显示更新提示。
