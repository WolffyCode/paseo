交互注解

布局
桌面三栏位置不变；草稿、乐观消息和真实对话使用同一底部 Composer 位置。
点击
“新对话”在当前中区打开草稿且 URL 不变；根对话切换中区；subagent 打开右栏。
首次进入
加载期间只显示 loading 指示；工作目录加载完成后直接显示默认“新对话”草稿与本图 Composer，不出现“选择一个对话”。
加载
首次发送后用户消息先在 Composer 上方出现；真实 agent 创建成功后原位接管。
运行
沿用流式输出、停止、权限与输入反馈；输出只在 Composer 上方增长。
离线
入口禁用；已有内容保留，连接恢复后继续同步。
失败
创建失败保留草稿与底部 Composer，可原位修改并重试。
无项目
中区显示“先打开项目”，不跳转旧新建页。
归档
显示只读归档提示，不提供可误发送的活跃 Composer。
右键
中区不新增右键菜单；左树管理菜单保持原定义。
文件
消息文件链接在右侧工作面板打开，相对路径以当前 workspace 为根。
