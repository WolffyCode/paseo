# 需求 · 中区真实对话与新对话草稿

> 日期：2026-07-28 · 状态：闸 3 调试验收中 · 配套 UI：[ui.html](./ui.html)

## 1. 目标

主页中区承载左侧当前选中根对话的真实消息流与输入区，并承接左栏“新对话”的内嵌草稿。用户可以在不离开主页三栏工作壳的情况下阅读、继续或开始真实对话。

## 2. 入口与流程

1. 连接 host 后进入主页；项目与工作目录加载完成且中区没有显式目标时，按全局默认 workspace 规则自动显示“新对话”草稿与真实 Composer，不先显示“选择一个对话”。
2. 点击左侧根对话，中区切换到该对话，加载真实历史并显示既有消息流与 Composer。
3. 切换另一条根对话，中区整体切换，不能短暂混入上一条对话的消息或输入状态。
4. 点击 subagent 仍按左侧对话树既定规则打开右栏，不替换中区当前根对话。
5. 点击消息中的文件链接，右侧工作面板打开对应文件；相对路径以当前对话工作目录为根。
6. 点击左栏顶部“新对话”后，URL 保持 `/home`，中区显示当前工作区的 draft Composer；项目右键“新对话”使用该项目的工作区。
7. draft Composer 从首帧固定在中区底部。发送第一条消息后，用户消息、运行输出和回复从 Composer 上方出现，Composer 的视觉位置不移动。
8. 创建成功后，中区原位切成真实 agent，左树新增并选中该根对话；创建失败时保留草稿和输入位置以便重试。

## 3. 状态

- 首次加载：中区等待项目与工作目录快照；加载成功后直接进入默认新对话草稿，不停留在“选择一个对话”空态。
- 加载：沿用真实对话面板的 agent 详情与历史加载态。
- 正常：显示消息流、工具调用、附件、subagent 轨道和 Composer。
- 运行：沿用真实对话面板的流式输出、停止与输入反馈。
- 错误：沿用真实对话面板的连接、历史同步和 agent 错误态。
- 离线：保留已加载内容，沿用现有重连与不可发送反馈。
- 归档：显示归档提示，不把归档会话伪装成可继续输入的活跃会话。
- 工作区缺失：不构造虚假工作区，中区保持可恢复空态。
- 新对话草稿：显示真实 Composer，画布内容区留在其上方；不显示旧新建页的主页式内容。
- 新建中：第一条乐观消息出现在 Composer 上方，Composer 保持底部锚点且发送控件进入既有 loading 状态。
- 新建失败：在草稿内容区显示既有错误反馈，保留输入和 Composer 锚点。
- 无可用工作区：显示“先打开项目”的内嵌提示，不导航到旧 `/new` 或项目选择页。

## 4. 交互边界

- 本需求只承接根对话到中区；subagent 的右栏对话类型继续由后续右栏需求承接。
- 不重写消息气泡、工具调用、Composer、timeline 同步或 agent 生命周期。
- 不新增协议、RPC、provider 或模型选择机制。
- 左侧预览假数据只用于树密度调试；中区展示的数据必须来自 daemon 的真实 agent/timeline。
- 左栏折叠时，当前中区选择保持不变；切换 host 时，选择与数据按 host 重建。
- “新对话”只切换 Shell 中区目标，不改变路由；工作区解析集中在树模型，不由 UI 临时猜测。
- 自动初始化只在加载成功且没有选中根对话、已打开草稿或待接管 agent 时发生，不能覆盖任何显式中区目标。

## 5. 验收

1. 导入一条本地真实 provider 会话后，左树出现对应根对话。
2. 点击该行，中区显示这条会话的真实历史，不是 JSX fixture。
3. 在两条根对话间切换，消息身份始终正确。
4. 折叠再展开左栏，中区仍保持当前对话。
5. 文件链接可打开右侧文件面板，且相对路径解析到当前 workspace。
6. 首次加载、错误、离线、归档与无 workspace 状态均有明确出口，无死路；首次加载成功后直接显示新对话草稿。
7. 顶部和项目菜单“新对话”均停留 `/home`，且选中正确 workspace。
8. 第一条消息发送前、乐观发送中、真实 agent 接管后，Composer 的底部位置保持一致，消息只在其上方增长。
9. 创建失败可原位重试；无 workspace 显示内嵌提示；重载后已创建的真实对话仍存在。
10. 初始化期间已有选中根对话、手动草稿或待接管 agent 时，加载完成不能覆盖该目标。
