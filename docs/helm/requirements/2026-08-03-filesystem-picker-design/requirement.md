# 本机工作目录选择器：项目快速选择与双栏浏览

## 目标

工作目录入口先提供紧凑的项目快速选择；需要浏览其它目录时，进入 Helm 的本机双栏文件系统浏览器。目录选择器不显示 Host 身份，也不承担本机 / 远程设备切换。

## 统一入口

1. 点击 Composer 上方的工作目录入口，在当前节点正上方打开紧凑浮层。
2. 浮层默认显示搜索框、最近项目和当前选中项目；搜索只过滤项目。
3. 点击项目后立即回填工作目录并关闭浮层。
4. 底部显示“浏览文件系统…”与“不使用工作目录”。
5. 点击“不使用工作目录”后切换为纯对话；再次打开仍可选择项目或浏览文件系统。
6. 取消、Escape 和点击外部不改变原选择与 Composer 输入。

## 双栏文件系统浏览器

1. 点击“浏览文件系统…”后，在工作目录节点正上方把紧凑浮层切换为双栏浏览器。
2. 左侧显示常用位置与可展开目录树，包括主目录、桌面、下载和项目目录。
3. 右侧显示当前路径下的完整目录列表，包括名称与修改时间。
4. 左右两栏高度固定并分别支持滚动；长目录名与长路径不会撑破面板。
5. 顶部提供返回、前进、当前位置路径和当前目录搜索；搜索只过滤右侧当前层。
6. 单击目录选中，双击或按 Enter 进入；左侧位置单击后切换右侧目录；“选择此目录”确认当前选中目录。
7. 返回、进入、树节点展开、选择、搜索、空目录、加载、错误和权限不足均有明确状态与出口。

## 平台与边界

- 本需求只覆盖 PC Electron 与桌面 Web，不设计手机端。
- 本期只处理当前电脑的文件系统，不设计远程 Host 或多设备目录浏览。
- 目录选择器内部不显示“本机 / 远程”标签或切换器；设备上下文由应用外层决定。
- 浏览器只展示目录，不把文件作为工作目录目标。
- 确认后必须返回 daemon 可解析的真实绝对路径；浏览器文件句柄不能替代该路径。

## 验收标准

- 页面中不存在本机 / 远程切换器、远程 Host 文案或远程浏览入口。
- 项目搜索、项目选择和“不使用工作目录”可以实际操作。
- 点击“浏览文件系统…”进入可操作的本机双栏浏览器。
- 左右双栏可以分别滚动，并可验证位置切换、树展开、目录选中、双击进入、返回、搜索和确认。
- 980px 及以上 PC 视口中面板完整显示，不与 Composer 重叠，也不被画布裁切。
